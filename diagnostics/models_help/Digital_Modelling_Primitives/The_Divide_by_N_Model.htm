The Divide by N Model - DIVIDER

The DIVIDER primitive models a divide by N frequency divider. The division ratio (N) is defined as a component property and the Q output changes state on every N'th clock edge unless the reset (RST) is active. In this case, Q is force to the inactive state.

 

Pin Type Pin Set Description
CLK Input - Clock Input
RST Input - Asynchronous reset input
Q Output - Normal output

 

Time Type From/To Edge Default
TDCQ Delay CLK → Q Both 0
TDRQ Delay RST → Q# Both 0
TGQ Glitch ANY → Q Pulse 0
