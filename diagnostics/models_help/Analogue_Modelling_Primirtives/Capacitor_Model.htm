The Capacitor Model - CAPACITOR

This is a pure device. Lead resistance, inductance and leakage are not modelled.

The capacitor model supports the following properties:

Property Default Description

PRECHARGE - Initial capacitor voltage. This property is a PROSPICE specific extension to standard SPICE. If the property is not specified, the capacitor's initial voltage is taken from the operating point.

IC - Initial capacitor voltage, useable only if initial DC solution is not computed.
