PROSPICE MODEL PARAMETERS

This help file contains context sensitive help for simulator primitives provided by PROSPICE.

Whilst you can browse it using the table of contents on the left, you will also find that the topics are directly linked to the components with the ASIMMDLS and DSIMMDLS libraries.

To access the help for a component already on the schematic, edit it by pointing at it and pressing CTRL-E, and then click the Help button at the bottom left.
