MULTIPLEXED LED DISPLAY

Introduction

LEDMPX.DLL can be used to simulate an arbitrary array of LED display segments which are driven by a matrix of common digit and segment wires. Typical applications included blocks of two or two or more 7 segment displays in which the segment lines are commoned but it could also be used to model rectangular dot matrix type LED modules.

The LEDs are modelled at the digital level only; there is no attempt to simulate their analogue behaviour (i.e. diode characteristics). However, provision is made to model a persistence of vision delay, so that a steady display can be achieved, not withstanding the multiplexed nature of the drive signals.

LEDMPX is a combined active component and digital simulator model. Logic levels detected at the row and column pins are used to select and display the corresponding active symbols for each segment of each digit. The best way to understand how to use the model is to decompose one of the existing devices that is based on it such as 7SEG-MPX4-CA.

Symbol Naming

The ISIS library part should be created as a bitwise active symbol, with one bit (thus two symbols) per segment. For a typical example see BITWISE INDICATORS in the Proteus VSM SDK.

You may be required to sign an NDA in order to gain access to the SDK.

A common symbol must also be defined, as this is used by LEDMPX.DLL to determine the width of a digit (or column).

This scheme avoids the need to define a separate active symbol for each and every segment in the display; only two symbols (on and off) for each segment of the left most digit need be drawn.

Pin Naming

The LEDMPX model will automatically detect the number of segments (rows) and digits (columns) on the parent device. Segment pins should be named 'A' - 'H' whilst digit pins should be named '1', '2', '3', '4'.

If you are attaching the device to a physical PCB footprint in ARES, you should use pin names as above, and pin numbers to match the footprint. Do not confuse digit numbers with pin numbers!

The Maximum number of rows and/or columns is set at 8.

Polarity

By default, a segment is drawn as lit if the corresponding row and column pins are both high for more than 1us during a given animation frame (typically 50ms). This gives a crude but effective representation of persistence of vision; in the real world, the segments are driven with a heavy current for short period of time, and the eye averages out the brightness.

To model common anode or common cathode displays, you can use the INVERT property to list the pins that are active low.  For example, a display with four common cathode digits would need the property:

INVERT=1,2,3,4
