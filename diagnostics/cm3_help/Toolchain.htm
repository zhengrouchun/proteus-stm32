INTERNAL DEBUG MODULE

In addition to source level debugging, model diagnostic messaging and other standard debugging windows, the Cortex-M3 module incorporates an internal debugging module which allows you to send messages to the ISIS simulation log from your firmware. This is implemented as a single read/write register (at address 0xFFFFFF00). the user would write some text to this address with a trailing zero and the text would then be displayed in the simulation log window.

Typical Usage:

#ifdef TARGET_PROTEUS

void print_str(const char* s)

 { char* dbgout = (char*) 0xFFFFFF00;   // Addressing the debugging module

   while(*s)

    { *dbgout = *s;                     

      ++s;

    }

   *dbgout = 0;                         // Trailing zero – required!

 }

#endif
