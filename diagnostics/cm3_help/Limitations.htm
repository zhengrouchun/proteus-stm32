MODEL LIMITATIONS

General Model Limitations

The following summarises the limitations in the model, correct at the time of writing:

General

  1. Bitband alias regions are of type XN (Execute Never). Fetches from these regions are invalid.
  2. Cache information is not used.
  3. SysTick Calibration value Register (SYST_CALIB) is ignored.
  4. Alignment of memory accesses is not analyzed
  5. Data Barrier instructions (DMB, DSB) are treated as NOP.
  6. Simulations are unlikely to run in real time with high clock speeds. This will affect performance but not accuracy of simulation.

System Control

  1. Register PLLCFG is not modeled
  2. Reference to unknown RCC2 register is not modeled - it exists in fact but is not described in the datasheet
  3. Clock Verification Timers are not modeled.
  4. Internal brown-out (BOR) detector is not implemented.

GPIO

  1. Register ODR is dummy – writing doesn’t change the model behavior.
  2. Registers DR2R, DR4R, DR8R, SLR are not modeled.

I2C Module

  1. Loopback feature is not modeled due to lack of information
