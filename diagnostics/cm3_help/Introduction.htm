Each processor is packaged per the datasheet with one or more of QFP, QFN, TQFP, PQFN or LGA footprints.

Datasheets for each device are available via the Data button on the Edit component dialogue form of the device. Please check the Texas Instruments website (www.ti.com) for the latest information and errata on these devices.
