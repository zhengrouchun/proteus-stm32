MODEL PROPERTIES

The following is a list of the properties available for configuration in the CM3 Models:

Program Property

This property specifies the name of the program file that will be loaded into the model. The file should be either Intel Hex (.HEX) or ELF (.ELF) format. The file extension must be specified as this is used to determine the format of the program file.

Crystal Frequency

This property specifies the main clock frequency of the processor. For reasons of efficiency, you can set this parameter to appropriate value other than 0, but in this case modifying registers of the SYSCTRL Module will not affect this frequency.

Setting this value other than 0, you should not use of PLL registers (especially tuning system frequency), because in this case the SYSCTRL Module is bypassed.

Clock Scale

Clock scaling is a performance optimisation that is applied to the CPU, Timer and TimerAC modules. All other peripherals are not affected. It allows a speed up of the simulation process by eliminating some iterations of "non-productive loops" (i.e. waiting for flag changes, and eternal dummy loops).

But it does have some limitations:

1) The CPU frequency scaling leads to less IPS (instruction per second), so a time delay using loops and a software generation of waveforms will be inaccurate.

2) The Timer/TimerAC modules will obtain some quantization of the counter, so it leads to inaccurate timings of generated waveforms in the internal clocking modes.

We recommend that this is left at the default value unless the firmware program requires it to be OFF. Clock Scaling OFF is cycle accurate simulation at the expense of optimised performance.

Disassemble Binary Code

This property controls internal disassembler behavior. It can be useful if you want trace librarian code or inspect code flow (every instruction) since processor started. If this feature is disabled and user press “Start Debug”, program run till first source line. Otherwise, if this feature is enabled, execution stops at the first instruction after Power-On-Reset.

Warning Messages

The LM3S3XX model may issue a warning message when it detects illegal or ambiguous behavior. The display of messages is controlled by “Configure Diagnostics”.

A list of all warnings issue by the model are listed below.

Unresolved address 0x12345678

There is no peripheral module having specified address.

Unknown target bus for address 0x12345678

Recipient of the bus transaction owns specified address is not found.

Invalid register request at 0x12345678

There is no known peripheral register at specified address.

Unpredictable memory region cross while writing

Instruction tries to access to different peripheral modules at the same time.

Access to register of unclocked peripheral at 0x12345678 cause BUS_FAULT

Instruction at PC=0x12345678 tries to access to peripheral module whilst it is disabled. The BUSFAULT exception is raised.

Stack frame integrity failed

Stack integrity mechanism works with exception processing and can detect erroneous stack writes in handler routines

Invalid access

Write access to read-only memory region.

Oscillator source is Main Oscillator (disabled)

Main oscillator is selected as a clock source, but it is disabled (RCC.MOSCDIS =1).

Oscillator source is Internal Oscillator (disabled)

Internal oscillator is selected as a clock source, but it is disabled (RCC.IOSCDIS =1).

RCC.OSCSRC = 3 (reserved value)

The bitfield RCC.OSCSRC has reserved value and can lead to undocumented behavior.
