MARKERS

Marker Types

Markers are used in the creation and editing of devices, symbols, terminals and pins. The following fixed set of types is provided:

Marker Type Purpose

ORIGIN

 Defines the anchor point of any part. The anchor point is the point which the object maybe rotated and corresponds to the mouse position at the time of placement.

NODE

 Defines the position of the wire connection point for a pin or a terminal

BUSNODE

 As above, but defines the pin or terminal as being of bus type. A bus line (thick and blue) will be drawn from the bus note to the origin.

LABEL

 Defines the position and orientation of a label for a pin or terminal.

PINNAME

 Defines the position and orientation of the pin name for a pin.

PINNUM

 Defines the position and orientation of a pin number for a pin.

INCREMENT

 Used in creating Active Component simulator models, this marker defines a Hot-Spot for incrementing the state variable

DECREMENT

 Used in creating Active Component simulator models, this marker defines a Hot-Spot for decrementing the state variable

Placing Markers

Markers are placed in the same way as graphics symbols (which is really what they are!).

To place a marker:

  1. Select the Marker Icon from the Mode Selector toolbar.
  2. Select the Marker you wish to place from the Object Selector.
  3. Use the Rotation and Mirror icons to orient the marker according to how you want it to appear on the drawing (a preview of the current rotation will appear in the Overview Window). This is only appropriate for LABEL, PINNAME and PINNUM markers - orientation is irrelevant for the other types.
  4. Left click the mouse on the Editing Window to enter placement mode.
  5. Move the mouse to the location on the Editing Window where you want to place the marker.
  6. Left click the mouse to place the marker and exit placement mode.
