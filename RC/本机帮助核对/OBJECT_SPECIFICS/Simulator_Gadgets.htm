SIMULATOR GADGETS

The interface to the ProSPICE simulator makes use of certain special objects within Proteus.  The complete set consists of:

  • Generators.
  • Voltage Probes.
  • Current Probes.
  • Graphs.
  • Tapes.
  • Active Popups.

Instructions pertaining to the use of these objects are provided in the Proteus VSM Help documentation.
