Global Annotator

Overview

This dialogue allows you to re-annotate all or part of the schematic with an initial annotation reference.

Options

Scope

Determine the scope of the annotation according to these options.

  • Whole Design - Specify annotation over the entire design.
  • Current Branch - Specify annotation from the current level of the sheet hierarchy downwards. Will include any sub-circuits derived from the current sheet.
  • Current Sheet - Specify annotation over the current sheet only.

Mode

Determine the mode of the annotation according to these options.

  • Total - Will re-annotate all parts in the selected scope.
  • Incremental - Will re-annotate only parts that do not have an annotation.

Initial Count

Specify the initial value for the annotator. For example, if you set this to be 7 then the relevant components will be annotated with suffix’s 7,8,9,10,etc.

Note:

You can also perform global or total annotation of the schematic based on the physical (geometric) layout of the board in the ARES layout module as follows:

  • If live netlisting is off (Tools menu in ARES) then turn it on.

  • Launch Automatic Annotator from the Tools Menu in ARES and specify starting point and direction.
  • The schematic annotation will update automatically after the layout annotation completes.
