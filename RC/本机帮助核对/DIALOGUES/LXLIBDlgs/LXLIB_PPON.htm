Position Printer Output Numerically

Overview

This dialogue form allows you to more accurately specify how you would like the output to be presented when printed by using numerical values.

Options

Top, Left, Right, Bottom

The textboxes allow you to numerically specify left, right, top and bottom margins. Note that if, for example, you enter a left margin, the right margin will be adjusted automatically according to the current paper size settings.

Buttons

The buttons will auto-position the output area at a preset position relative to the paper size (e.g. top left, bottom right, etc..).More information on printer output is provided within both the ISIS and ARES online documentation.

Metric Units?

Uncheck the metric checkbox to display all settings and values in imperial units. When checked all values are displayed in metric units.
