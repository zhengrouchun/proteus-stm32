Keyboard Mapping

Overview

This dialogue allows you to assign all commands in ARES to keyboard shortcuts of  your choice.

Please note that the documentation refers to keyboard shortcuts in their default assignation.

Options

Command Groups

Use this selector to filter the command sets according to which command(s) you want to assign a keyboard shortcut for. All mappable commands are logically sorted into groups and each group is selectable from this combobox.

Available Commands

This view will list all commands available for mapping within the command set specified by the selector above. To specify a command for mapping left click once on the appropriate command (to highlight the command) and then click the mouse in the keyboard assignation box below.

Key Sequence for Selected Command

Specify the keyboard shortcut for the command highlighted in the above viewer. This field is disabled if no command is highlighted. More information on keyboard shortcuts can be found here.

  • Assign - Confirm that the specified keyboard shortcut is to be assigned to the highlighted command.
  • Unassign - This command will unbind the currently assigned keyboard shortcut (as displayed in the text to the right of the highlighted command) from the highlighted command.
