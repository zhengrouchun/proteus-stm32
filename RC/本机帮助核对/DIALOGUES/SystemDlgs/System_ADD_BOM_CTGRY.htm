Add BOM Category

Overview

In order to group similar parts together in the Bill of Materials output the system applies categories according to the reference prefix of the component. For example, all resistors have reference prefix 'R' and all capacitors have reference prefix 'C'. The reference prefix is set on the first tab of the Make Device dialogue form and you can therefore create additional categories of components if you choose.

This dialogue form allows you to add an additional category of components to the Bill of Materials output and optionally to specify several reference prefixes to associate with this category.

Options

Category Heading

Specify the heading you want for the category. This text should describe the type of components listed in the category.

Reference(s) to Match

Specify the reference prefixes you want to include this category. Each component on the schematic  has a reference prefix (R for resistors, C for Capacitors etc.) which allows you to easily group types of component within a category.

Mark this category as the miscellaneous category?

Each template should have a miscellaneous category into which all component with a reference prefix not previously allocated can be placed. For example, if you create two catagories, one for capacitors (reference prefix C) and one for resistors (reference prefix R) then any component with a reference prefix other than C or R will be placed in the miscellaneous category.

Output separate References for each component?

When checked all references will be output individually. This means, for example, if you have 15 10k resistors you will get 15 rows, one for each resistor. When unchecked, you will get a single row indexed as R1-R15.
