Set BOM Scripts

Overview

The Bill of Materials output is the primary report generated from the Proteus schematic module and details the parts used in the design. You can add arbitrary information to the BIll of Materials report by adding properties to components on the design and then adding the property name as a field in the Bill of Materials report. This dialogue form allows you to control which information (properties) are displayed in the output and also provides various formatting options.

The report itself is then generated from the output options at the top of the BOM module.

Options

Scripts

Specify  the Bill of Materials script that you want to use for your BOM Output. By default, three scripts are provided which you can customise as required. You can also create your own scripts tailored to your own requirements.

  • New - Create a new Bill of Materials script.
  • Rename - Rename the currently selected Bill of Materials script.
  • Delete - Delete the Bill of Materials script currently selected in the combo box to the left of this button (this operation cannot be undone). Note that you cannot delete the last script - ISIS requires that there is always at least one bill of materials script.

Bill of Materials Output Format

Specify the format of the Bill of Materials output. The following formats are available:

  • PDF Output - Formats your outputs as a PDF File. This is the most common format and enables presentation features such as colouring and company logos to be included.
  • ASCII Text - This plain text output is readable by notepad and any other common text editing application.
  • CSV (Compact) - This format is directly loadable into Microsoft Excel spreadsheet . Groups of components where all the specified columns are the same are grouped together.
  • CSV (Full) -  This format is directly loadable into Microsoft Excel spreadsheet . Each part is output independantly regardless of similarities in the columns.

Categories

Displays a list of current catagories for the Bill of Materials.  These catagories delineate the Bill of Materials, grouping the components in logical groups.

  • Add - Add a category to the current Bill of Materials Template.
  • Delete - Remove the currently selected category from the current Bill of Materials Template. This button is only enabled when a category is highlighted in the selector above the button.
  • Edit - Edit the category currently selected in the catagories selector. This button is only enabled when a category is highlighted in the selector above the button.
  • Order - Use this button to specify the order of the catagories currently in the selector.

Fields (Columns)

This selector displays the fields (or columns) to be used for each component in the Bill of Materials.

  • Add - Add a field (a column) to the selected Bill of Materials template. You can use this to add custom fields or simply to include information already provided by the components default properties.
  • Delete - Remove the currently selected field from the Bill of Materials. This button is only enabled when a field is highlighted in the selector above.
  • Edit - Edit the currently selected field. This button is only enabled when a field is highlighted in the selector above.
  • Order - Specify the order of the fields currently in the column selector.

Import/Export

These options provide mechanisms for copying, pasting, saving and loading BOM scripts and are intended to allow custom BOM scripts to be shared across machines.
