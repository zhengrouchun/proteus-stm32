Add BOM Field

Overview

Each component has a base set of properties associated with it and users can add additional properties if required ( through the Make Device dialogue form, the property assignment tool or ASCII data import commands). In the Bill of Materials output each column or field is associated with a property and the value of the property for a given component populates that column in the resulting output. For example, you may wish to add properties for COST or RoHS to your components so that the bill of materials contains this information.

This dialogue allows you to add properties as fields in the report and provides configuration options for formatting and validation.

Options

Component Property Name

Specify the property to associate with the field being created/edited. The ‘list’ button allows you choose from a list of all the properties currently on the schematic.

Title for Column Heading

Specify the title for the column. This should be a textual description of the values which will be placed in the columns.

Property Validation

This combo box allows you to specify a degree of validation for the component property name specified above. This can help prevent errors or unintentional omissions in your final Bill of Materials.

Column Width

For ASCII output this value specify the number of characters that can be in the column. The column in clipped at the width of the column as specified by this value and any extra characters/text will be lost.

Prefix

This field allows you to add a prefix to the values for this field.(for example, a currency designator for monetary fields).

Suffix

This field allows you to add a suffix to the values for this field.(for example, a unit specification).

Apply Prefix/Suffix to blank (empty) values?

This checkbox determines whether the chosen prefix/suffix is applied to empty fields and is only enabled if you have values entered for either the prefix or the suffix.

Default Field Value

This field allows you to specify a default value where no value is present for the specified property within the component.

Output Sub-Totals/Totals For this Field

This checkbox enables the subtotalling (per category) and totalling of column values. Particularly useful for monetary values.
