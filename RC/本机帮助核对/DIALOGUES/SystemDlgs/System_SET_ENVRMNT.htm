Set Environment

Overview

This dialogue enables configuration of several application environment preferences.

Options

Autosave Time

Specify the time delay between automatic saves of the current design.

Number of Undo Levels

Specify the number of undo levels you want to keep. Obviously the more undo levels the more memory ISIS requires in order to store each stage.

Tooltip Delay

Specify the time the mouse must be held over an icon before the tooltip message for that icon appears.

Number of Filenames on File Menu

Specify the number of filenames that you want in the Most Recently Used list on the File Menu.

Auto Synchronise/Save with ARES?

Specify whether or not you want the ISIS to automatically back-annotate from ARES whenever it is brought to the foreground. If this option is selected, the ARES file will automatically be saved whenever ISIS is brought to the foreground.

Save/Load ISIS state in Design files?

Specify whether or not you want the general editing state of ISIS to be saved with the design file. For example, when checked this will store the mode you are in and the current sheet and will start up in that mode and on that sheet when next you load the design.
