Set Display Options

Overview

This dialogue form allows customization of the display options within ISIS allowing you to change animation and graphics mode settings.

Options

Graphics Mode

Check the different box depending on which graphics mode you wish your computer to use, some graphics cards will support Open GL in hardware.

Auto-Pan Animation

This provides control over the smooth panning of the board.

  • Panning Distance -  Setting the distance moved.
  • Number of Steps - The smoothness of the scroll (the more steps the smoother the scroll).
  • Pan Time  -  The speed according to personal preference.

Highlight Animation

The highlight animation options control what happens when the mouse is placed over an object

  • Attack Rate - The speed at which items highlight when the mouse is placed over the object.
  • Release Rate - The speed at which an object highlight will disappear.

Multi-Sampling

Allows to change the anti-aliasing of text on the display providing your graphics card supports the options.
