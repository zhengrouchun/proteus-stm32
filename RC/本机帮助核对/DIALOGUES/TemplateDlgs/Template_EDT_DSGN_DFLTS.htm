Edit Design Defaults

Overview

This dialogue allows you to configure default styles and colours for the work environment in ISIS and for interactive simulation. If you want to persist these changes for future designs you need to use the Save as Template command on the File Menu when you have finished configuration.

Options

Colours

Use these options to specify global colour preferences  for various objects on the schematic. Each option has its own context sensitive help topic.

  • Paper Colour - This is the colour used as the ‘background’ colour of the ISIS editing and overview windows.
  • Grid Colour - Specify the colour of the grid dots in the main editing window.
  • Work Area Box Colour - Specify the colour of the box drawn in the overview window which shows the part of the schematic currently in the editing window.
  • World Box Colour - Specify the colour of the box drawn in both the editing and the overview windows that shows the maximum sheet extents.
  • Highlight Colour - Specify the colour used for tagged objects.
  • Drag Colour - Specify the colour used when entering objects such as wires, graphics, subcircuits, etc. as well as when an object is dragged.

Animation

Use these options to specify colours for various animation conditions. Each option has its own context sensitive help topic.

  • Positive Colour - Specify the colour of a wire at a positive potential. This colour is blended with the ground colour for potentials between zero and the maximum wire animation voltage value.
  • Ground Colour - Specify the colour of a wire at ground potential.
  • Negative Colour - Specify the colour of a wire at a negative potential. This colour is blended with the ground colour for potentials between zero and the minus the maximum wire animation voltage value.
  • Logic '1' Colour - Specify the colour of a wire when at a logic ‘1’ state.
  • Logic '0' Colour - Specify the colour of a wire when at a logic ‘0’ state.
  • Logic '?' Colour - Specify the colour of a wire when at an undefined or floating state.

Hidden Objects

Use these options to configure defaults for hidden objects. Each option has its own context sensitive  help topic.

  • Show Hidden Text? - Specify whether or not any hidden properties should be displayed on the schematic.
  • Show Hidden Pins? - Specify whether or not to display any hidden power pins on the schematic.
  • 'Hidden' Colour - Specify the colour in which you want hidden objects to appear if made visible.

Font Face for Default Font

The TrueType™ font face name that is used wherever the Default Font is selected as the font face for text styles or 2D graphics text.

Render Master Sheet?

When checked the contents of the master sheet will be rendered on all sheets in the design. Unchecking this option will mean that the contents of the master sheet will not be drawn on any sheet on the schematic.
