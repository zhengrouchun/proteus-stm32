Set Graphics Text

Overview

This dialogue allows you to specify the font and font attributes for 2D graphics text placed on the schematic. If you want to persist these changes for future designs you need to use the Save as Template command on the File Menu when you have finished configuration.

Options

Font Face

Set the initial font face for the 2D Graphics text. This is the initial or default font but can be altered using the Edit 2D Graphics Dialogue form.

Text Justification

These checkboxes allow you to define the required justification for the text.

Effects

Use these options to configure default effects for the text.

Character Sizes

  • Height - Specify the initial height for 2D Graphics Text. This will become the default height but can be altered as required using the Edit 2D Graphics Dialogue form.
  • Width - Specify the initial width for 2D Graphics Text. This will become the default width but can be altered as required using the Edit 2D Graphics Dialogue form.
