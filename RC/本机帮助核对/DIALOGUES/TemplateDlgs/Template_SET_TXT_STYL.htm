Set Text Styles

Overview

This dialogue form allows you to edit different styles for your text enabling you to change the font face, size, colours and add effects while allowing you to see a sample of the style.

Options

Style

Specify the name of the current global style being edited. When a new style is selected, the previous style is automatically updated with any changes made to its attributes.

  • New - Click to create a new global style. The new style is initialised with settings taken from the controls on the dialogue form when it is created so the new button also effects a ‘copy’ operation. Note that you cannot create a new style with the same name as an existing style.
  • Rename - Click to rename the current global style. You cannot rename any of the predefined (system) styles – when one of these styles is selected the Rename button is disabled. You cannot rename a style to the same name as an existing style.
  • Delete - Click to delete the currently selected global style. You cannot delete any of the predefined (system) styles - when one of these styles is selected the Delete button is disabled. Selecting this button causes a confirmation to be displayed after which the style is deleted. A deleted style cannot be recovered using the Undo button. Once a style is deleted, any local styles in the design using the style as their parent style are updated to use the most appropriate system style as their parent.
  • Undo - Click to undo any edits to the currently selected Global Style. Note that  Rename and Delete operations cannot be undone using this button.
  • Close - Click to close the dialogue form and commits any changes made to the currently selected style.

Font Face

Specify the name of the font face the text is to be displayed in. The drop down list lists all the TrueType™ fonts available on the machine as well as two special fonts: Default Font and Vector Font.

The Default Font causes the text to be displayed in the design-global default font as set on the Set Design Defaults dialogue form. If you use Default Font on all your styles then you can globally control the font face used in the design via the Set Design Defaults command on the Template menu.

The Vector Font causes the text to be displayed in an internal proprietary vector font which is particularly suited for plotters and other vector output.

Height

Specify the height of the text. You can use whatever standard units you like, such at th for thou (thousandths of an inch) or mm for millimetres.

Width

Specify the width of a character in the text. This field is only enabled for text to be drawn in the internal Vector Font (either explicitly or by selecting the Default Font where the default font has been set to be the Vector Font).Units can be specified as for the Height field.

Colour

Specify which colour the text is to be drawn in.

Effects

 Use these options to configure default effects for the text.

Sample

The sample box displays a sample of text drawn with the current style settings. Note that text drawn in the 'paper' colour or where the Visible check box is not checked, no text will be visible.
