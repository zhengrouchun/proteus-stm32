Configure Junction Dots

Overview

This dialogue allows you to specify the style and size of junction dots placed on the schematic. If you want to persist these changes for future designs you need to use the Save as Template command on the File Menu when you have finished configuration.

Options

Size

Specify the global size of wire junction dots.

Shape

Use these options to globally specify the shape of wire junction dots. Note that to change graphical appearance of wire junction dots you need to edit the WIRE DOT graphics style with the Set Graphics Styles command on the same menu.
