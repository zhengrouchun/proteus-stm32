Set Graphics Styles

Overview

This dialogue is the main configuration tool for the appearance of the objects on the schematic. Select the object type you wish to edit and then set the attributes as desired. When you are finished you need to use the Save as Template command on the File Menu if you wish to persist the settings for future designs (all new designs are derived from a template).

Options

Style

Specify the name of the current global style being edited. When a new style is selected, the previous style is automatically updated with any changes made to its attributes.

  • New - Click to create a new global style. The new style is initialised with settings taken from the controls on the dialogue form when it is created so the new button also effects a ‘copy’ operation. Note that you cannot create a new style with the same name as an existing style.
  • Rename - Click to rename the current global style. You cannot rename any of the predefined (system) styles – when one of these styles is selected the Rename button is disabled. You cannot rename a style to the same name as an existing style.
  • Delete - Click to delete the currently selected global style. You cannot delete any of the predefined (system) styles - when one of these styles is selected the Delete button is disabled. Selecting this button causes a confirmation to be displayed after which the style is deleted. A deleted style cannot be recovered using the Undo button. Once a style is deleted, any local styles in the design using the style as their parent style are updated to use the most appropriate system style as their parent.
  • Undo - Click to undo any edits to the currently selected Global Style. Note that  Rename and Delete operations cannot be undone using this button.
  • Import - Click to import a global graphics style.
  • Close - Click to close the dialogue form and commits any changes made to the currently selected style.

Line Attributes

  • Line Style - Specify the line style used for drawing lines, arcs and the outside boundaries of boxes, circles, paths, etc. The (none) option allows you to draw filled graphics with no bounding lines.
  • Width - Specify the line thickness for solid line styles. A width cannot be specified for dot/dash style lines as these can only be drawn with a single pixel width. You can specify a value of zero which forces ISIS to draw the line as a single device pixel regardless of any device resolution and/or scaling applicable at the time the line is drawn.
  • Colour - Specify the line colour.

Fill Attributes

  • Fill Style - Specify the type of fill to be applied to any closed area within the graphic object. The None option indicates the object is not to be filled (i.e. it is transparent), the Solid fill indicates the object is to be completely filled whilst the other fill styles indicate the object is to be given a hatched fill.
  • FG Colour - Specify an FG Colour.This option is only applicable for a solid or hatch fill; where no fill is specified this control is disabled. The foreground colour is the colour used for the solid fill or for the hatch lines in a hatched fill.
  • Use Bk. Colour? - This option is only applicable for a hatched fill; where none or a solid fill is specified this control is disabled. Deselecting this checkbox indicates that the 'gaps' between the lines of a hatched fill are to be transparent. Selecting this checkbox indicates that the 'gaps' are to be (solid) filled in a additional, background colour.
  • Bk. Colour - Specify a background colour. This option is only applicable for a hatched fill and where the Use Bk. Colour? Checkbox is selected (checked). Where none or a solid fill is specified this control is disabled, or where a hatched fill is specified and the Use Bk. Colour? checkbox  is not selected (unchecked) this control is disabled. The background colour is the colour used to fill in between the lines of a hatched fill.
