Set Y-Axis Scaling

Overview

This dialogue allows you to specify a Y-Axis scaling for the current graph once a data set has been stored on the graph.

Options

Left Axis

The options within this groupbox allow you to manually specify the Y-Axis range for the left hand Y-Axis. Note that these options are only enabled for applicable graph types and after the graph has already been simulated.

Right Axis

The options within this groupbox allow you to manually specify the Y-Axis range for the right hand Y-Axis. Note that these options are only enabled for applicable graph types, where the right hand Y-axis has traces on it, and after the graph has already been simulated.
