Simulation Options - Iteration

Integration Method

Specifies an integration method  (can be either Gear or Trapezoidal).

Trapezoidal Integration is provided mainly for backward compatibility with previous versions of SPICE since Gear integration generally gives more accurate results for a given number of time-steps.

In Gear integration, higher orders than 2 are possible; this involves SPICE using more of the past history of a time-point in predicting what happens at the next time-point.

Maximum Integration Order

Specifies the maximum level of integration for a particular integration method. This is limited to an order of 2 for the Trapezoidal Method but higher orders are permitted for the Gear Method.

Number of Source Steps

Specifies the number of steps you want in SPICE’s Source Stepping mode. This is an approach utilied by SPICE when it fails to find convergence at the operating point. All power supplies in the circuit are started at zero and are ramped up to their proper values in  a number of steps as determined by this parameter.

Number of GMIN Steps

Specifies the number of steps you want in SPICE’s GMIN Stepping mode. This is an approach utilized by SPICE when it fails to find convergence at the operating point. The GMIN parameter is increasingly reduced until convergence occurs, and then ramped back to its proper value. The number of attempts is determined by this parameter.

DC Iteration Limit

Specifies the maximum number of iterations that will be tried at the operating point.

DC transfer curve iteration limit

Specifies the maximum number of iterations that will be tried at a step in a Transfer Curve Analysis.

Upper Transient Iteration Limit

Specifies the maximum number of iterations that will be tried at a time point in a Transient Analysis.

Go directly to GMIN stepping?

Specifies whether or not you want SPICE to directly adopt the GMIN Stepping mode. SPICE uses this mode when it fails to find convergence at the operating point.

Try compaction for LTRA lines?

Specifies whether or not you want LTRA compaction performed on the simulation. This applies only for circuits incorporating lossy transmission lines (LOSSYLINE model). The idea is that near identical values in the data pipeline get discarded so that this data points are processed.

Allow bypass on unchanging elements?

Specifies whether or not you want to bypass unchanging elements in the simulation. This is a general optimization that saves SPICE from re-computing the values of semiconductor devices whose node voltages have not changed since the last evaluation.
