Graph Colour Configuration

Overview

This dialogue form allows you to customise the graph to be colours of your choice.

Options

General Appearance

Use these options for general configuration. Each option has its own context sensitive help topic.

  • Graph Outline - Specify the colour used for borders and dividing lines on the graph.
  • Background - Specify the background colour used to fill the main part of the graph.
  • Graph Title - Specify the background colour used to fill the title bar.
  • Graph Text - Specify the colour used for text used to label and mark the graph axes. Trace labels always appear in the same colour as the trace.
  • Tagged/Highlight - Specify the colour used to highlight the graph or individual trace when it is tagged.

Analogue Traces

Specify the colour(s) by which you want to identify the various analogue traces.

Digital Traces

Specify the colour(s) by which you want to identify the Digital Traces on the graph.
