Simulation Options - MOSFET

Options

MOS drain diffusion area

Specifies the default drain diffusion area for MOSFET models.

This is intended to be used in IC modelling where it is useful to specify the model parameters in terms of physical dimensions.

MOS source diffusion area

Specifies the default source diffusion area for MOSFET models.

This is intended to be used in IC modelling where it is useful to specify the model parameters in terms of physical dimensions.

MOS Channel Length

Specifies the default channel length for MOSFET models.

This is intended to be used in IC modelling where it is useful to specify the model parameters in terms of physical dimensions.

MOS Channel Width

Specifies the default channel Width for MOSFET models.

This is intended to be used in IC modelling where it is useful to specify the model parameters in terms of physical dimensions.

Use older MOS3 Model?

Activates 'bug emulation' for certain MOSFET models which were developed for earlier release of SPICE 3.

Use SPICE2 MOSFET Limiting?

Actives 'old style' Kappa limiting for MOSFET models that were developed for SPICE 2.
