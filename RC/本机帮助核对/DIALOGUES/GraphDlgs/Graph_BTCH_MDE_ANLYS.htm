Batch Mode Conformance Analysis

Overview

This dialogue form enables you to automatically run a set of designs which contain conformance graphs. Each design is simulated and the conformance results analysed and presented in a textual report at the end of the process.

For more information on conformance testing and conformance graphs please refer to the VSM Help under Analysis Types.

Options

Root Path

Specify the root directory where the designs containing the conformance graphs are stored.

Recurse Subdirectories?

Run the batch processing through not only the specified directory above but also through any subdirectories inside the root directory.

Stop on Error?

Stop the batch processing if a conformance error is detected.

Log Detailed File Information ?

This option enables detailed reporting of conformance results and provides more information on completion than the standard output.
