Edit Transfer Function Graph

Overview

This graph type is specifically designed for producing characteristic curve families for semiconductor devices, although it occasionally finds other applications. Each curve consists of a plot of operating point voltage or current against the value of a nominated input generator which is swept from one DC value to another. An additional generator may also be stepped to produce a set of curves.

Options

Graph Title

Specify the title that appears along the top of the graph. By default, this is set to the type of analysis determined by the graph's type.

Source 1

Specify the name of the first generator to sweep.

  • Start Value - Specify the initial value for the first generator.
  • Stop Value - Specify the final value for the first generator.
  • No. Steps - Specify the number of steps PROSPICE will take in incrementing the first generator. This translates into the number of points on a curve.

Source 2

Specify the name of the second generator to sweep.

  • Start Value - Specify the initial value for the second generator.
  • Stop Value - Specify the final value for the second generator.
  • No. Steps - Specify the number of steps PROSPICE will take in incrementing the second generator. This will determine the number of curves in the simulation.

Left Axis

Specify the left axis label.

Right Axis

Specify the right axis label.

User Defined Properties

The Properties free-format text field allows you to define Simulation Control Properties that will be fed to the simulator engine when the graph is simulated. Recommended only for advanced users. You can also use this field to define values that appear in component property expressions. This technique is particularly useful if you wish to create several graphs showing the effect of changing one or more component values.

Options

  • Always Simulate? - When checked this forces a graph to perform a simulation regardless of whether or not the partition or partitions on which the simulation depends has changed.
  • Log Netlists? - When checked this causes the simulation netlist generated by ISIS and fed to the simulator engine to be placed in the graph's simulation log.
  • SPICE options - Pressing this button activates a dialogue form that enables you to adjust global simulator options that are common to all types of analysis.
  • Set Y-scales - This option allows you to manually configure the ranges for the Y-axes of the graph. Note that you must have performed an initial simulation before manually setting or locking the Y-Axis of the graph.
