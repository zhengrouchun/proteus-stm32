Edit Transient/Conformance Graph

Overview

This graph type represents what you might expect to see on an oscilloscope. The x-axis shows the advance of time, whilst the y-axis displays voltage or current. We often refer to this type of analysis as Transient Analysis because it takes place in the time domain.

Transient analysis is perhaps the most commonly used form of analysis. Everything that you would measure with an oscilloscope on a real prototype can be measured on an analogue graph. It can be used to check that the circuit operates in the expected manner, to take quick measurements of gain, to assess visually the way in which a signal is distorted, to measure the current flowing from the supply or through individual components, and so on.

Options

Graph Title

Specify the title that appears along the top of the graph. By default, this is set to the type of analysis determined by the graph's type.

Start Time

Specify the nominal time from which simulation results will be displayed.

Stop Time

Specify the time the simulation is to cease at. Times such as 100u will be correctly interpreted by ISIS as 100ms. The right end of the graph time axis is set by this field.

Left Axis Label

Specify the frequency at which the simulation is to stop.

Right Axis Label

Specify the right y-axis label.

Options

  • Initial DC Solution - Specify that at time = 0 all capacitors, inductors etc. are at steady states. If this is unchecked then when the simulation starts all inductors will be defluxed and all capacitors will be discharged.
  • Always Simulate - This check box forces a graph to perform a simulation regardless of whether or not the partition or partitions on which the simulation depends have changed.
  • Log Netlist(s) - This check box causes the simulation netlist generated by ISIS and fed to the simulator engines to be placed in the graph's simulation log.
  • Spice Options - Pressing this button activates a dialogue form that enables you to adjust global simulator options that are common to all types of analysis.
  • Set Y-scales - This option allows you to manually configure the ranges for the Y-axes of the graph. Note that you must have performed an initial simulation before manually setting or locking the Y-Axis of the graph.

User Defined Properties

The Properties free-format text field allows you to define Simulation Control Properties that will be fed to the simulator engine when the graph is simulated. Recommended only for advanced users. You can also use this field to define values that appear in component property expressions. This technique is particularly useful if you wish to create several graphs showing the effect of changing one or more component values.

Verification

Use these options to either store a known good set of results or to clear the stored results. Subsequent to storing a set of results any future simulation on this graph will be analysed for conformance against these results (according to the control trace edges).
