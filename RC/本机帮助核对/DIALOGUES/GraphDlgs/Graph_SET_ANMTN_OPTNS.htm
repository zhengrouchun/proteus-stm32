Set Animation Options

Overview

This dialogue allows you to configure various simulation parameters for use in interactive/animated simulation.

Options

Simulation Speed

Use these options to configure simulation speed. Each option has its own context sensitive help associated with it.

  • Frames per second - Specify how many animation frames are shown every second. The range for this option is 1 to 50. The lower the value the slower the animation will run. The higher the value the faster the animation will run. On Windows 95/98 there is no benefit in setting it higher than 20.
  • Timestep per frame - Specify by how much the simulation times advances for each frame. It follows that if you change the frame rate, you must also change the timestep per frame if you wish to maintain real time simulation. Alternatively, you can set a smaller timestep per frame if you wish to slow down the rate of progress of the simulation. This value represents the desired timestep which will only be achieved if there is sufficient CPU power for the speed of operation and complexity of the circuit.
  • Single Step Time - This is used in conjunction with the STEP button and determines the time advanced for each single step. In logic circuits it is often useful to set this to half of the clock period so that the effect of  each clock transition can be observed.
  • Max SPICE Timestep - This setting clamps the simulation to a maximum timestep. The higher this value the faster the simulation at the expense of accuracy.
  • Step Animation Rate - This is the rate at which the automatic single step debugging will progress. At default value 4, the system will step over four instructions per second when automated stepping is enabled.

Animation Options

Use these options to configure general animation options. for interactive simulation. Each option has its own context sensitive help associated with it.

  • Show Voltage and Current on Probes? - When checked this option will enable a small live readout of voltage / current beside a probe on the schematic during animation where the readout is determined by the type of probe used on the schematic.
  • Show Logic state of pins? - If checked, then coloured blobs are drawn next to the pins of all logic devices in order to indicate their logic state. This option imposes an extra but modest computational burden on the simulator.
  • Show wire voltage by colour? - If checked, then the voltage of analog nets is displayed by colouring the wires. The scaling for this is determined by the value given in the Maximum Voltage field, above.
  • Show wire current with arrows? - If checked, then current flow within wires on analog nets is displayed using small arrows. An arrow is drawn for any current flow greater or equal to the value given in the Current Threshold field, above. This option can impose a major computational burden on the simulator, because each wire is replaced by a 1mÙ resistor, thus substantially increasing the number of components and circuit nodes. In digital simulation, the presence of the resistors causes a doubling of the number of events to be processed.
  • SPICE options - This button launches the SPICE simulation options dialogue, allowing advanced users to further configure simulation tolerances etc.

Voltage/Current Ranges

Use these options to configure voltage and current ranges for interactive simulation. Each option has its own context sensitive help associated with it.

  • Maximum Voltage - Specify  the scaling for the active wire colours. You would normally set it to the highest voltage occurring in your circuit.
  • Current Threshold - Specify the minimum value of current flow within a wire for which an arrow will be displayed. Occasionally it may be useful (for educational clarity) to increase this value so that the circuit behavior will appear idealized, not withstanding the use of real world models. For example, you may wish to have an op-amp appear to draw no input current when in fact a given SPICE model may draw a few microamps from its inputs.
