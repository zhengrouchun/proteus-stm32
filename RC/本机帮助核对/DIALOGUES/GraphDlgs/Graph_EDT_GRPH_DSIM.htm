Simulation Options - DSIM

Options

Random Initialization Values

  • Fully Random Values - Specifies that the initialization values for each model in the design with a scaleable timing value will be completely random both on the initial simulation and through repeat simulations.
  • Pseudo-Random values based on seed - Specifies that the random numbers generated are dependant on a seed value. This, in effect, means that while all capable models receive random values ( which are dependant on the value of the seed that you specify ) they will receive those same values on repeat simulations. This is particularly useful for isolating errors in the simulation.

Propagation Delay Scaling

  • Scale all values by constant amount - When this option is checked all propogation delays for models in DSIM will be scaled by the amount specified. For example, a high to low edge propogation delay of 10ns will actually take 20ns if this setting is selected and a value of 2 is specified.
  • Pseudo-random scaling based on seed - When this option is checked propagation delays are randomized within the bounds specified according to seed. The fact that the randomization is seeded ensures that the ordering is constant and so subsequent simulation runs will produce the same ‘random’ values as the initial simulation.
  • Fully Random Scaling - Selects an option from those given to indicate how you would like DSIM to handle propagation delay in the models on the design. See the context sensitive help on each edit field for more information. The Upper and Lower Scaling Limits fields specify the limits for random propogation delays and ensure that random delays have sensible boundaries.
