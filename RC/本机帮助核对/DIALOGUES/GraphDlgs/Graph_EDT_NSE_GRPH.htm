Edit Noise Graph

Overview

The SPICE simulator engine can model the thermal noise generated in resistors and semiconductor devices. The individual contributions of noise are summed together at a voltage probe in the circuit for a range of frequencies. The noise voltage, normalised with respect to the square root of the noise bandwidth, can then be plotted against frequency. Traces on a noise graph always have units of V/ÖHz.

Two types of noise figure are computed - Output Noise and Equivalent Input Noise. The computation of the latter enables comparison of the noise with the input signal, or input noise, since it represents the level of noise at the input that would be required to create the actually noise at the output taking into account the circuit gain at a particular frequency.

Placing a probe on the left axis displays output noise, whilst equivalent input noise can be displayed by dragging the probe onto the right axis.

Noise analysis tends to produce extremely small values (of the order of nanovolts). For this reason, there is the option to display them in dBs. The 0dB reference is 1V/ÖHz.

Options

Title

Specify the title that appears along the top of the graph. By default, this is set to the type of analysis determined by the graph's type.

Reference

The generator used as the input source – this defines the point for which Equivalent Input Noise is computed.

Start Frequency

The noise bandwidth frequency at which the simulation will start.

Stop Frequency

The noise bandwidth frequency at which the simulation will end.

Interval

 Specify whether the number of steps is per decade, per octave or is linearly spaced across the whole plot.

No. Steps/Interval

Specify the number of steps per the selected interval. For the linear interval this is the number of points plotted across the whole x-axis.

User Defined Properties

The Properties free-format text field allows you to define Simulation Control Properties that will be fed to the simulator engine when the graph is simulated. Recommended only for advanced users. You can also use this field to define values that appear in component property expressions. This technique is particularly useful if you wish to create several graphs showing the effect of changing one or more component values.

Options

  • Y-scale in dBs - If checked the left y-axis will display the magnitude in dBs.
  • Log total contributions - If checked, the total noise contribution (summed from all spot frequencies) from each component in the design is recorded in the simulation log.
  • Log Spectral Contributions - If checked, the noise contribution from each component at each spot frequency is recorded in the simulation log. This can generate a very large amount of data.
  • Always Simulate - When checked this forces a graph to perform a simulation regardless of whether or not the partition or partitions on which the simulation depends has changed.
  • Log Netlist(s) - When checked this causes the simulation netlist generated by ISIS and fed to the simulator engines to be placed in the graph's simulation log.
  • SPICE Options - Pressing this button activates a dialogue form that enables you to adjust global simulator options that are common to all types of analysis.
  • Set Y-Scales - This option allows you to manually configure the ranges for the Y-axes of the graph. Note that you must have performed an initial simulation before manually setting or locking the Y-Axis of the graph.
