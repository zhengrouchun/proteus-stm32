Edit Audio Analysis Graph

Overview

PROTEUS VSM incorporates a number of features that enable you to hear the output from your circuits (providing you have a sound card, of course!). The major component of this is the Audio graph. This is essentially the same as an Analogue graph except that after simulation, a Windows WAV file is generated from the time domain data and played through your sound card.

The WAV files can also be exported for use in other applications.

Options

Graph Title

Specify the title that appears along the top of the graph. By default, this is set to the type of analysis determined by the graph's type.

Start Time

Specify the start of the time period that will be used to generate the WAV file.

Stop Time

Specify the end of the time period that will be played. Bear in mind that asking  PROSPICE to generate several seconds of audio containing several thousand cycles of a waveform will take a considerable amount of time.

Play Mode

Specify a play mode from one of the following options:

  • MONO - Generates a WAV file from the aggregate of all the traces on the graph.
  • STEREO - Generates a stereo WAV file routing the left hand traces to the left channel and the right hand traces to the right channel.
  • INPUT - Generates a mono WAV file from the aggregate of the left hand traces. The right hand traces are merely displayed.
  • OUTPUT - Generates a mono WAV file from the aggregate of the right hand traces. The left hand traces are merely displayed.

Loop Time

To avoid the need for PROSPICE to simulate hundreds or thousands of cycles of a waveform, it is possible to generate a WAV file of several seconds in length by repeating one cycle many times. The Loop Time setting determines the desired length of the WAV file, and the interval from Start Time to Stop Time will be copied as many times as are needed to achieve this.

Sample Bits

Specify the number of bits per sample for the WAV file. 8 bit gives about 48dB dynamic range and 16 bit gives 96dB.

Sample Rate

Specify the number of samples per second for the WAV file. Remember that the maximum frequency that can be played back is half the sample rate. Also, at present there are no fancy pre-filtering algorithms implemented and so aliasing effects will be heard if the sample rate is too low.

Lock Timestep?

This option locks PROSPICE’s internal timestep to the desired sample rate. This can result in much quicker (albeit slightly less accurate) simulations and reduced partition file sizes - useful if you are processing several seconds of audio as file sizes can otherwise quite easily exceed 10Mb.

User Defined Properties

The Properties free-format text field allows you to define Simulation Control Properties that will be fed to the simulator engine when the graph is simulated. Recommended only for advanced users. You can also use this field to define values that appear in component property expressions. This technique is particularly useful if you wish to create several graphs showing the effect of changing one or more component values.

Options

  • Initial DC Solution - Specify that at time = 0 all capacitors, inductors etc. are at steady states. If this is unchecked then when the simulation starts all inductors will be defluxed and all capacitors will be discharged.
  • Always Simulate - When checked this forces a graph to perform a simulation regardless of whether or not the partition or partitions on which the simulation depends has changed.
  • Log Netlist(s) - When checked this causes the simulation netlist generated by ISIS and fed to the simulator engines to be placed in the graph's simulation log.
  • SPICE Options - Pressing this button activates a dialogue form that enables you to adjust global simulator options that are common to all types of analysis.
  • Set Y-scales - This option allows you to manually configure the ranges for the Y-axes of the graph. Note that you must have performed an initial simulation before manually setting or locking the Y-Axis of the graph.

Audio

Play Audio - This option allows you to play stored audio data through your computers sound card.

Export as WAV file - This option allows you to export the currently graphed data as a WAV file. You can then optionally import this into another design using the audio generator.
