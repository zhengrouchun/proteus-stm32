Simulation Options - Tolerances

Options

Absolute Current Error Tolerance

Specifies the absolute current error tolerance of the program. This is the amount by which successive current values must match before convergence is achieved.

Absolute Voltage Error Tolerance

Specifies the absolute voltage error tolerance of the program. This is the amount by which successive voltage values must match before convergence is achieved.

Charge Error Tolerance

Specifies the charge error tolerance for the program. This is the amount by which successive charge values must match before convergence is achieved.

Relative Error Tolerance

Specifies the relative error tolerance for the program. This is the threshold of relative change in current, voltage or charge values that must be attained for convergence.

Minimum acceptable pivot value

Specifies the absolute minimum value for a matrix entry to be accepted as a pivot in solving the circuit equations.

Minimum acceptable ratio of pivot

Specifies the relative ratio between the largest column entry and an acceptable pivot value in solving the circuit equations.

Minimum Conductance

Specifies the minimum conductance allowed by the program. This value defines the leakage of reverse biased semiconductor junctions and other theoretical points of infinite impedance. Reducing this value may help achieve convergence for circuits that fail to simulate - although this may be at the expense of simulation accuracy.  Values greater than 1E-9 will give very dubious results.

Minimum Transient Conductance

This is a Labcenter specific convergence optimisation which provides a dynamic way of increasing GMIN to improve convergence during transient analysis.

Shunt Resistance

This is the resistance to ground from all nodes in the circuit.
