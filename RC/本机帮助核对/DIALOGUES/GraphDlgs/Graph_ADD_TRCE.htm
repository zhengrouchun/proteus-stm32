Add Trace

Overview

This dialogue allows you to add one or more traces to a graph and to use multiple traces to form a trace expression (e.g. Power) which can then be plotted on the graph.

Options

Name

Enter the name of the trace to be added to the graph.

Probe P1

Select a probe or generator from the list box to be assigned to the selected trace probe. The Selected Probe name (P1 through P4) will appear in the Expression field if it is not already present.

Probe P2 - P4

Select a probe or generator from the list box to be assigned to the selected trace probe. The Selected Probe name (P1 through P4) will appear in the Expression field if it is not already present. This is only enabled if a trace expression is permitted.

Expression

Enter the trace expression in the Expression field. Within the expression, the selected probes should be represented by the names P1, P2, P3 and P4 which correspond to the probes selected alongside the P1, P2, P3 and P4 buttons respectively. If the trace type selected does not support a trace expression the contents of the Expression field will be ignored.

Trace Type

Select the type of trace you wish to add to the graph by checking the appropriate button. Only those trace types applicable to the graph are enabled.

Axis

Select the y-axis to which the new trace is to be added. Only those axes applicable to the graph and trace type selected are enabled.
