Edit AC Sweep Graph

Overview

This type of analysis creates a family of frequency response curves for a different values of a swept variable.

The main use for this graph type is in seeing how a particular component value affects the frequency response of your circuit.

Options

Graph Title

Specify the title that appears along the top of the graph. By default, this is set to the type of analysis determined by the graph's type.

Reference

Specify a generator to use as the source of the test signal.

Start Frequency

Specify the frequency the simulation will start at. This must be greater than 0, and less than the stop frequency.

Stop Frequency

Specify the frequency the simulation will cease at.

Interval

Specify whether the number of steps is per decade, per octave or is linearly spaced across the whole plot.

No. Steps/Interval

Specify the number of steps per the selected interval. For the linear interval this is the number of points plotted across the whole x-axis.

Sweep Var

Specify the name of the variable that is to be swept. This defaults to X, but any variable name may be used, including control properties like TEMP.

Start Value

Specify the initial value of the swept variable. This may be a negative value.

Stop Value

Specify the final value of the swept variable. This may be negative, but must be greater than the start value, as negative going sweeps are not allowed.

Nom Value

Specify the value for the sweep variable to use when computing the operating point.

No. Steps

Specify the number of steps that PROSPICE will take in incrementing the swept variable.

User Defined Properties

The Properties free-format text field allows you to define Simulation Control Properties that will be fed to the simulator engine when the graph is simulated. Recommended only for advanced users. You can also use this field to define values that appear in component property expressions. This technique is particularly useful if you wish to create several graphs showing the effect of changing one or more component values.

Options

  • Y-scale in dBs? - If checked, the left y- axis displays the magnitude in dBs.
  • Always Simulate? - When checked this forces a graph to perform a simulation regardless of whether or not the partition or partitions on which the simulation depends has changed.
  • Log Netlist(s) - When checked this causes the simulation netlist generated by ISIS and fed to the simulator engines to be placed in the graph's simulation log.
  • SPICE Options - Pressing this button activates a dialogue form that enables you to adjust global simulator options that are common to all types of analysis.
  • Set Y-scales - This option allows you to manually configure the ranges for the Y-axes of the graph. Note that you must have performed an initial simulation before manually setting or locking the Y-Axis of the graph.
