Export Bitmap

Overview

Use this dialogue form to export your design as a standard Windows bitmap. If you don't check the Output To File option, the bitmap will be placed on the clipboard.

Options

Scope

Select which part(s) of the design you wish to export from the given options. Note that not all of the options may be available at any one time.

  • Marked Area - Export the marked area as set by the Set Area command on the File menu. This option is only enabled where there a marked area and there is no maximised graph.
  • Current Graph - Export the currently maximised graph. This option is only enabled where a graph has been maximised. To maximise a graph either select the graph title from the bottom of the Graph menu or click left once on the graph's title bar.
  • Current Sheet - Export the currently displayed sheet. This option is only enabled where there is no maximised graph.
  • All Sheets - Export all sheets, including root sheets and hierarchical sub-sheets. This option is only enabled where there is no maximised graph.

Resolution

Choose from 100 to 600 DPI. Memory usage increases in proportion to the square of the resolution so a 600 DPI bitmap needs 36 times as much memory as a 100 DPI bitmap. A 100 DPI bitmap in 256 colours needs 10k bytes per square inch (5kB if in 16 colours).

Colours

Specify the colour depth of the export from the options given.

  • Mono - Print the exported graphic in monochrome (black and white)
  • 16 - Print the exported graphic in 16 colours.
  • 256 - Print the exported graphic in 256 colours.
  • Display - Print the exported graphic using the same bitmap format as your display adapter.

Rotation

The Virtual Graphics Device subsystem can produce output with the x dimension either vertical or horizontal on your peripheral. This lets you use the length of your peripheral to best effect. For example, with a wide carriage 9 pin printer it is possible to print an A2 sheet at 1:1 scaling though this will take a considerable amount of time.

Output to File?

Use these options if you want to export to a file.
