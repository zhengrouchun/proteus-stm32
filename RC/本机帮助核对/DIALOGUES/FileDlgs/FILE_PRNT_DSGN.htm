Print Design

Overview

This dialogue allows you to configure the scale and range of the schematic for printing.

Options

Printer & Output Device

This allows you to specify and configure the printer output device for the current print job. Note that selecting a different print device here will not change the default printer for ISIS. You can specify the default printer for use with ISIS via the Printer Setup option on the File Menu.

  • Printer - Use this button to configure the printer device for the current print job.
  • Filename - Click to specify a path and filename for the file to be exported.

Options

Use these options to specify colour output or to use the Labcenter Plotter Driver. Note that the plotter driver button is only enabled if you have specified a plotter device (via the printer button on the left).

  • Print in Colour? - Check this box to specify colour output. Note that some printers do not support this mode.
  • Labcenter Plotter Driver? - If this option is checked then ISIS only relies on the plotter driver’s ability to draw a line on the plotter with ISIS linearising arcs, circles, etc. and rendering text in a vector font. If this option is not checked then ISIS treats the plotter driver just like any other driver and expects it to sensibly handle all Windows GDI calls. This option is only enabled when a plotter is selected as the output device.

What to Print

The options in this groupbox allow you to configure which areas of the design you wish to print. Note that the print preview is disabled when printing all sheets.

  • Marked Area - Export the marked area as set by the Set Area command on the File Menu. This option is only enabled where there a marked area and there is no maximised graph.
  • Current Graph - Export the currently maximised graph. This option is only enabled where a graph has been maximised. To maximise a graph either select the graph title from the bottom of the Graph menu or click left once on the graph's title bar.
  • Current Sheet - Export the currently displayed sheet. This option is only enabled where there is no maximised graph.
  • All Sheets - Export all sheets, including root sheets and hierarchical sub-sheets. This option is only enabled where there is no maximised graph. Note that no print preview is available with this option and the sheets will position with origin at the centre of the printable area. For more control over sheet position select the ‘Current sheet’ option and print for every sheet individually.

Copies

Specify the number of copies you want for the current print job. Note that if your printer does not support multiple copies this field will be disabled.

Scale

These options allow you to specify the appropriate scaling factor for your output area. The print preview will display the output area at the current scaling. Note that the Scale to Fit option will, by default, only shrink a large design down to fit the paper size. To enlarge a small design to fit you must first uncheck the Only Shrink to Fit option.

Only Shrink to Fit? - This checkbox is only enabled when the ‘Scale to Fit’ option is selected. When checked the output area will, if necessary, shrink to fit within the printable area. It will not however, expand a smaller area to the bounds of the printable area. When unchecked designs can be both shrunk and expanded to the printable area.

Page Orientation

These options specify whether the document should be printed with its top along the short side of the paper (Portrait) or along the long side of the paper (Landscape). The print preview will automatically update to provide a visual representation of the specified orientation.

Compensation Factors

The compensation parameters scale the absolute co-ordinates of the graphic leaving the relative size(s) unaffected. For example, if you have a line of length 10 units drawn at co-ordinates (5, 5) and you set the x-compensation =  0.6 and the y-compensation =  0.5, then the line would actually be outputed at co-ordinates  (3, 2). The length (10 units) remains unaffected. The purpose of these parameters is therefore to allow dimensionally critical designs to be of sufficient accuracy.

Print to File?

Specify whether or not you want to save the print job to disk.

Advanced Options

These options allow you to override the information that your printer supplies to ISIS and should only be used when the information supplied is incorrect. We advise you to use these options with caution – for example, enabling colour options on a printer which does not support colour output is pointless and will achieve nothing.
