EXPORT SVG

Overview

This dialogue form allows you to export the current layout in Scalable Vector Graphics (SVG) format.

Options

Scope

Select which part(s) of the design you wish to export from the given options. Note that not all of the options may be available at any one time.

  • Marked Area - Export the marked area as set by the Set Area command on the File menu. This option is only enabled where there a marked area and there is no maximised graph.
  • Current Graph - Export the currently maximised graph. This option is only enabled where a graph has been maximised. To maximise a graph either select the graph title from the bottom of the Graph menu or click left once on the graph's title bar.
  • Current Sheet - Export the currently displayed sheet. This option is only enabled where there is no maximised graph.

Options

Specify any particular options for the dialogue form.

  • Colour Output? - Specify whether or not the output will be in colour or monochrome.
  • Background Colour - Select a background colour for the exported layer set. Some caution is required to ensure sufficient contrast and visibility of the output.
  • Launch Viewer? - View the exported SVG file in your system viewer on completion.

Rotation

Specify the desired x-rotation for output.

Our Virtual Graphics subsystem can produce output with the x-dimension either vertical or horizontal on your peripheral. This lets you orient your work most naturally within the Layout Editor  and still be able to make the best use of the size of your peripheral when producing artwork.

The terms x-horizontal and x-vertical will depend also on the whether you have selected portrait or landscape mode for the print device itself. On a portrait page we define horizontal to mean parallel to the short edge.

Output To File?

Browse your hard disk to select a directory and file into which to save the output.
