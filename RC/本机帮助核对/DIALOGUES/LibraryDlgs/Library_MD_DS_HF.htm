Device Datasheet & Help File

Overview

This screen allows you to associate a datasheet and a help file with the component. When configured a data and help button will appear on the edit component dialogue form.

Options

Datasheet

Use these options to link a manufacturers datasheet to the library part. You can specify a path to an HTTP or FTP site. Each field has its own context sensitive help associated with it.

  • Filename - Specify the filename of a manufacturer's datasheet for the component. If none of the other fields are filled in, the data sheet is assumed to be available from the Labcenter download site. Otherwise, you can fill in the other fields to specify an alternative location for the file. The extension (usually PDF) is required, and the filename may be case sensitive for some download sites. If you specify a filename in this field, then ISIS will add a Data button to the Edit Component dialogue form.
  • Download Server - Specify the HTTP or FTP site on which the datasheet file may be found. E.g. http://downloads.labcenter.co.uk or ftp://ftp.microchip.com If you leave this field blank, the datasheet will have to be manually downloaded and put in the datasheets directory within the installation directory.
  • Download Path - Specify the path (directory) in which the datasheet is located on the HTTP or FTP server. This field may be case sensitive for some download sites.
  • Download User ID - Specify the user id for the HTTP or FTP server login. Leave this field blank where authorization is not required.
  • Download Password - Specify the password for the HTTP or FTP server login. Leave this field blank where authorization is not required.

Help Topic

Use these options to link in a help project to your library part. These options tend to be used where you have a simulation model associated with the part and want to describe tolerances, properties and functionality for that model in the form of some help documentation. Each field  has its own context sensitive help associated with it.

  • Help File - Specify the name of a Windows Help file which contains information about this component. This is provided mainly as a means for providing usage information about simulator models. If you specify a filename in this field, then ISIS will add a Help button to the Edit Component dialogue form. This facility is intended for use in documenting simulator models.
  • Context Number - Specify the help context ID containing information about the component. You should cross-reference this number to a help topic ID using the MAP section of the Windows Help project file.
