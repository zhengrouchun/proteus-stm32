Options

General Properties

Use these fields to specify the  basic device information. Each field has it’s own context sensitive help associated with it.

  • Device Name - Specify the name for the new device.
  • Reference Prefix - Specify the Default prefix for newly placed components. If you blank out the prefix, then placed parts will initially have empty reference fields and their value and properties will be hidden. The reference prefix is also used to group like items together in the Bill of Materials report.
  • External Module - Specify the name of an external module file to attach to the component when it is placed. This allows you to define components which represent re-useable circuit elements. You can create an external module file by checking the External Mod File checkbox within the Edit Sheet Properties command.  For an ordinary physical component you should leave this field blank.

Active Component Properties

If your library part has an associated Active Component interface then use these options to link in the Active Component Model. This will only be the case if you are either editing one of our Active Components (for example,the keypad model), or have created your own VSM model . If you are simply creating a library part for use within the Schematic Capture package or for linking to ARES PCB design then you can safely leave these options in there default states. Each option contains it’s own context sensitive help topic.

  • Symbol Name Stem - Specify the stem of the name for the model. The symbol names will consist of the name stem an underscore and an appended number.
  • No. of States - Specify the number of states for the model. In the standard case this is the number of symbols created for the model. However if Bitwise States?  is checked then a separate symbol is required for both the on and off states and so the number of symbols required will be double the number of states.
  • Bitwise States? - Specify whether a  symbol is required for both on and off states (Bitwise States ) or not. A bitwise active component has symbols names of the form STEM_N_0 and STEM_N_1 for each element of the component.
  • Link to DLL? - Specify whether or not the component model is to be linked to a VSM Model DLL.
