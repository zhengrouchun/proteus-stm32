Package Device

Overview

This dialogue allows you to specify one or more packages to associate with the component. You can also specify hidden power pins and identify NC pins whilst the footprint preview gives you visual confirmation when all the pins on the schematic part are mapped onto the pads of the footprint.

Options

Packages

Lists all available packages. To change from one existing package to another click on the down arrow to the right of this field and select the desired package. If the package you want is not in this combo box you will have to create it via the add button located directly below this field.

  • Default Package? - By checking this box, you specify that the package currently selected in the packages combo box is to be used as the default package for this device. This in turn means that without intervention from yourself the component will use this package in future designs.
  • Add - Use this button to add a package to the component.  Should the Use ARES Libraries checkbox be selected a package viewer will launch from which you can browse to the package that you want to add. If you are not using the ARES Libraries (for example,.if you are drawing the schematic to be exported to another PCB design package), then clicking this button will launch a dialog box where you can enter the name of the package you wish to associate with the library part. Note that in this case no validation of the package is possible.
  • Rename - This button allows you to rename the packaging currently specified in the packages combo box. Should the Use ARES Libraries checkbox be selected a package viewer will launch from which you can browse to the package with the name that you want to us. If you are not using the ARES Libraries (for example,.if you are drawing the schematic to be exported to another PCB design package), then clicking this button will launch a dialog box where you can manually rename the package you wish to associate with the library part. Note that in this case no validation of the package is possible.
  • Delete - This option allows you to delete the package currently selected in the packages combo box.
  • Order - This option allows you to re-order the existing packages to your preference and is disabled if you have only one package specified for the device currently being packaged.

No. of Gate

 This field determines the number of pin-number columns that appear in the pin grid. For a multi-element heterogeneous part, it should represent the total number of elements. For most common devices (e.g. resistor, capacitor etc.) this field can be left in its default state (single element).

Gates can be swapped on the PCB Layout?

Selecting this checkbox will flag to ARES that the gate elements can be swapped.

Pin Selection Window

This is the engine of the Visual Packaging tool and where you assign pins on the schematic part to pads on the PCB footprint.  Some points of note are listed below :

  • If you have a package preview on the right hand pane and you assign a pin number, the corresponding pad on the package will highlight in white. This means that when you have completely packaged the device all pads in the preview pane should be white
  • Again with the package preview you can set the focus in an elements pin field ( as if to type in the pin number) and then left click the mouse on the pad in the preview pane. This will assign the pin with the designation of the pad you have clicked on and move the focus to the next pin in the list. This can be a very fast and convenient way to manually package devices.
  • A number of options are available to you via the context menu (right click to access). These are mainly advanced features of the packaging tool but, properly used, can make large or multiple packages far simpler. See the help documentation for more details.

NC Pins

 When packaging a large device, it may be useful to 'prove' that all the pins have been accounted for by verifying that all the pins are highlighted in the Package View.  Since some pins may be specified as non-connected, it is useful to be able to record that they have been accounted for. This can be achieved by entering their numbers in the NC Pins field. Use commas to separate the pin numbers.

Add Pin - This option allows you to create a hidden pin that is specific to a given package, and is implicitly common to all its elements.

Remove Pin - This option allows you to remove a hidden pin that is specific to a given package,and as such has been created via the packaging tool.

Swappable Pins

The swappable pins section allows you to define groups of pins that are electrically interchangeable. For example, the two inputs A and B of a 7400 quad NAND gate are electrically identical can could be swapped on the PCB for convenience of wiring. You can add a swap-group to the list by highlighting the pins in the pin grid (hold the ctrl key down and click left on the pin names), and then clicking the Add button.

  • Add - This option allows you to add a group of swappable pins. Proceed by highlighting the pins in the pin grid (hold the CTRL key down and left click on each pin in turn), and then click this button to assign the highlighted pins as a swappable group.
  • Remove - This option allows you to remove a previously specified group of swappable pins. Simply highlight the group in the pinswap selector to the left and click on this control to remove the pins.
  • Replace - This option allows you to replace a previously specified group of swappable pins.  Highlight the pins in the pin grid that you want to add (holding the CTRL key down to highlight multiple pins) and then use this button to replace the group currently selected in the pinswap selector with the group you have just specified.

Use ARES Libraries

This option, selected by default, allows both package viewing and package verification. You should only disable this checkbox if you are creating the schematic for netlist to a different PCB design package.

Assign Package(s)

Commit any changes in the dialogue options and exit.
