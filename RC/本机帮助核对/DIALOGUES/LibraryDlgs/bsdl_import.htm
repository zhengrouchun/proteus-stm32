BSDL Import

Overview

This topic outlines the basic procedure for importing a BSDL file into Proteus.

More detailed information and guidance can be found via the HELP button at the bottom of the dialogue form or in the Library Facilities chapter of the reference manual.

Basic Procedure

  • Check whether the pins in the pin grid need re-ordering or re-naming. They will appear on the schematic in the same order as they appear in the pin grid.
  • Decide whether you want your power pins and/or NC pins to be visible or hidden. If hidden, power pins will connect automatically to the net whereas if visible you will need to tie them to a power terminal with the correct net name. Similarly, if you make the NC pins visible you need to place and connect NC terminals to each pin. This is discussed more in the help topic in the reference manual.
  • Check whether you need to split the part into several elements and add component separators in appropriate places. If you are using visible power and NC pins it's useful to split them off into their own elements.
  • Check whether blank line separators would help with clarity (for example, on either side of a bus) and add where appropriate.
  • Specify the direction of pin placement.
  • Continue to part naming, packaging, etc in the usual way.
