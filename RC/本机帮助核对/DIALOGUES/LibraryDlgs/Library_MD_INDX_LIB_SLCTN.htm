Indexing and Library Section

Overview

The final stage of creating a device is to specify which library you wish to store the part in and to provide categories and search (index) terms to make it easy to pick the part into designs. Note that you should never store your own parts in to Labcenter libraries as these libraries are overwritten on installation of a new version (to enable library updates).

Options

Device Category

Specify which category you wish the device to be indexed under. If no appropriate category is available you can add one of your own via the New button on the right. Indexing your parts makes them far easier to find when browsing and rationalizes the libraries into logical groups.

Device Subcategory

Specify which subcategory you wish the device to be indexed under. If no appropriate category is available you can add one of your own via the New button on the right. Alternatively, if no subcategory is appropriate for your part you can select ‘None’ from the combo list. Indexing your parts makes them far easier to find when browsing and rationalizes the libraries into logical groups.

Device Manufacturer

Specify which manufacturer you wish the device to be indexed under. If no appropriate category is available you can add one of your own via the New button on the right. Alternatively, if no subcategory is appropriate for your part you can select ‘None’ from the combo list.

Stock/Order Code

You can optionally specify a stock code for the part for use in the Bill of Materials report.

Device Description

This field is used to enter the description for the library part you are creating. You can search by description when browsing for library parts and the description string is displayed in the results listview. Care should be taken therefore to enter a description using terminology that you would use to easily search for the part.

Advanced Mode - When selected this checkbox will place the dialogue in advanced mode. This allows you to, for example, enter a comma separated list of categories if you want your part to be listed in more than one category. However, due to the free format nature of the advanced mode, we recommend that this is only used by experienced users.

Device Notes

This field can be used for entering any additional information about the library part being created. For example, we may use this field to enter helpful model information for simulatable. If a component has notes added to it, they are then viewable via the ‘View Notes’ button on the Edit Component dialogue form (this button is dynamic and so does not appear for components with no notes).

Save Device to Library

This viewer displays a list of all read-write libraries contained in your library path(s). To select a library to place your part in, left click to highlight that library in the viewer. If the library into which you want to place the part does not appear in the list check the following :

That the library is writeable – only read-write libraries will appear in this list.

That the library is in a directory specified in your library path (see System – Set Paths). If you need to move a library you will have to close and restart ISIS for the library to be reloaded.
