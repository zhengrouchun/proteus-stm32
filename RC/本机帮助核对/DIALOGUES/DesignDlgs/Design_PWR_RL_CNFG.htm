Power Rail Configuration

Overview

This dialogue form allows you to configure power connections and to connect supplies to rails. If you prefer you can do the same thing by wiring power terminals together on the schematic (e.g. VCC & +5V) - all such connections will be honoured by this configuration tool.

Options

Power Supplies

This groupbox contains a series of controls (each with it’s own context sensitive help) which allow you to configure the characteristics of all the power supplies on the schematic.

  • Name - Displays a list of existing power supplies for the current design. This list is populated both from the default set of power supplies (preconfigured and shipped with the software) , with any explicitly defined power supplied on the schematic and with any power supplies you have added via this dialogue form. For each power supply a list of power nets connected to the rail is displayed towards the bottom right of the dialogue.
  • New - Specify a new power supply. This allows you to create a power supply which you can then configure via the other options on the dialogue form.
  • Rename - Rename an existing power supply. This allows you to rename the currently selected  power supply. Note that if the power supply has been explicitly specified on the schematic (e.g. a power terminal annotated +12V) this field will be disabled.
  • Delete - Delete the currently selected power supply. Note that you cannot delete a power supply via this dialogue form where the power supply has been explicitly specified on the schematic.
  • Voltage - Set the voltage for the currently selected power supply. Note that power supplies which have been explicitly specified on the schematic (e.g. a power terminal annotated +12V) cannot have their voltage altered via this dialogue – this field will be disabled for such supplies.
  • Class - Set the strategy for the currently selected power supply. By default all supplies will be assigned the POWER strategy but, should a rail require particular consideration you can specify a custom strategy name here and configure design rules etc. for the strategy in ARES. Note that where a strategy has been specified explicitly on the schematic (e.g. a wire label annotated STRAT=FRED) you cannot change the strategy via this dialogue form.

Unconnected power nets

This listbox contains all the power nets currently on the schematic which have not been bound to a power rail. You can assign a net to a power supply by selecting the desired supply from the combo box above (or creating a new supply via the New button), left clicking on the net name within this listbox to highlight the net, and then clicking the mouse on the Add button to assign the net to the power supply.

Nets connected to GND

This listbox contains all power nets assigned to the power supply currently selected via the combo box at the top of the dialogue form. You can add unassigned power nets or remove existing power nets via the Add/Remove buttons to the left of the listbox.

Add

Use this button to assign a highlighted (unconnected) power net to the currently selected power supply. In the case where two (or more) power nets have been wired together on the schematic, assigning one net to a power supply will assign all the conjoined nets as well.

Remove

Use this button to remove a highlighted (assigned) power net from  the currently selected power supply. In the case where two (or more) power nets have been wired together on the schematic, removing one net from a power supply will remove all the conjoined nets as well.

Use default power rail connections

When checked the default power supplies will be applied to the current design. Note that at the point of activation this will supersede any manual edits that have been made to power supplies with the same names as those in the default set. We recommend that you leave this option enabled unless you specifically require customisation of the default power supplies.
