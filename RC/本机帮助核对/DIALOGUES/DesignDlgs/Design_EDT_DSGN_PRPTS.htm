Edit Design Properties

Overview

This dialogue allows you to provide design information for use both in the Bill of Materials report and during design netlist.

Options

Filename

Click to specify a path and filename for the file to be exported.

Title

Specify the title of the design. This will appear at the top of any reports generated from the design (BOM Scripts, Netlists etc.). Note that this is not the same as the filename.

Doc. No.

Specify the document number for the design. This will appear in any reports (e.g.  BOM scripts, Netlists etc.) that are generated from the design.

Revision

Specify the revision number. This will appear on any report generated from the design

Author

Specify the author of the design.

Nestlisting Options

These design configuration options each have their own context sensitive help topic.

  • Global Power Nets? - Specify whether power nets are to be assigned locally or globally (across all sheets).
  • Cache Model Files? - Specify whether or not model ( .mdf ) files are saved within the design files. If checked, this means that a design can be loaded and simulated by a third party who does not have the models used in the design.  Note, however, that VSM Model DLLs cannot be cached.
