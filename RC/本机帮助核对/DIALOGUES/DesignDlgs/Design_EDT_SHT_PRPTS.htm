Edit Sheet Properties

Overview

This dialogue allows you to specify various properties relevant to the current sheet.

Options

Module Name

The module name is the name of the current hierarchy level on the schematic design. For a single board project the root level of the schematic design is called ROOT and for a multi-board project it will be BOARD1, BOARD2 etc at the root level. Root level module names are not editable but modules names for other modules further down the sheet hierarchy (e.g. sub-circuits) can be changed.

Sheet Title

Specify the title of the sheet. The title is displayed on the Design Menu and other tools and can be changed to reflect the contents of the sheet.

Sheet Ordinal

The sheet ordinal serves only to determine the presentation order of the child sheets of a module. Only root modules can have multiple child sheets.

Annotator Init

Specify the annotation offset for the sheet. This value is used by the automatic annotator to determine the starting value for component references on the sheet and, in conjunction with the replicate command in ARES, can allow you to duplicate identical blocks of circuitry on the layout.


Board Local Part ID's

This option is relevant only for multi-board projects. The question here is whether the annotation should be global to the project or global to the board. The default is global to the board rather than the project but you can change this by unchecking this option. You would only need to do this for one sheet per board but if you choose to work with project global annotation it's really important that you do uncheck this option for every board otherwise you will end up with an annotation muddle.

In practise, we'd recommend board local annotation since it makes documentation like the BOM and Assembly Drawings more easily understood.

Non-physical sheet?

Specify whether or not the components on the sheet are to be included a a netlist for PCB layout. Check the checkbox for any sheet which is a simulator model as opposed to a physical part of the design.


Synchronise Siblings

It is possible in Proteus to have identical sub-circuits by providing the same circuit name to each sub-circuit. Then, whatever you place and wire on one sub-circuit is mirrored onto all others with the same name (E.g. left and right channels of an amplifier). By default, the property values on sub-circuits will also be maintained / kept the same (this option selected). For example, if you change a resistor to 470Ohm on one sheet the equivalent resistor on the other mirrored sheets will also change to 470Ohm. If you want to customize different sub-circuits and allow the parts on to have different properties on different sheets you need to uncheck this box.
 

External .MOD file?

Specify whether or not you want the sheet to be linked to an external .MOD file. This allows child circuits to be shared between designs. External MOD files are kept in the MODELS directory. Recommended for advanced users only.
