Edit Pin

Overview

This dialogue allows configuration of all pin properties.

Options

Pin Name

Specify the pin name. If the device uses a pinout, this must match the pin name that appears in it.

Default Pin Number

Specify the pin number. If the device uses a pinout, or if the pin is a bus pin, this field should be left blank.

Draw Body?

If checked, the pin stem will be drawn along with the name and number as defined by the Draw name and Draw number checkboxes. If not checked then the pin is deemed hidden and will not be drawn at all.

Draw Name?

If checked (along with the Draw body checkbox), the pin name will be drawn at the position defined in  the pin's symbol by the Pinname marker.

Draw Number?

If checked (along with the Draw body checkbox), the pin number will be drawn at the position defined in the pin's symbol by the Pinnum marker.

Rotate Pin Name?

This option, when checked, will rotate the pin name. This can be convenient where space is at a premium in some components.

Rotate Pin Number?

This option, when checked, will rotate the pin number as displayed on the schematic.

Electrical Type

Specify the electrical type of the pin. This is used by the electrical rules checker, and also by the PROSPICE simulation software.
