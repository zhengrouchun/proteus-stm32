Edit Subcircuit

Overview

This dialogue allows you to provide basic information about the sub-circuit.

Options

Name

The object name for the sub-circuit. If a flattened netlist is produced, this is taken as the sheet name for the child sheet. If the hierarchy is not flattened, then this field is used as the part name for the 'component' represented by the sub-circuit. This field must be different for each sub-circuit on a given sheet.

Circuit

The name of the child circuit to attach. This will be assigned automatically if you zoom into a sub-circuit for which this field is blank. On the other hand, if you want to attach several sub-circuits to the same child-circuit, you should enter the circuit name in this field. For example, if you are designing a stereo amplifier and want two sub-circuits named LEFT and RIGHT to use the same circuit for an amplifier channel, you might edit each one to have the circuit AMP.

Properties

Sub-circuits carry a property list in the same way that ordinary components do. When the design is flattened, these properties become sheet property definitions which may be used in parameterized expressions on the child sheet. It thus becomes possible to have different instances of a given circuit use different component values.
