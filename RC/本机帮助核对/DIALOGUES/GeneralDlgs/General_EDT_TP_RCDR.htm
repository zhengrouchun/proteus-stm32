Edit Tape Recorder

Name

Specify the name of the tape. You can change the name of a tape by typing in a new name into the name field. Once you have manually changed the name of a tape, ISIS will never replace it, even if you move the tape to a new net. Should you wish to revert back to automatic naming clear the name field and then click OK.

Properties

Include any additional properties or modify existing properties here. Text in curly brackets  { } will be hidden. The contents of this text block will be dependant on the type of generator used.

Mode

Specify whether the tape operates automatically, records to a named file, or plays a named file.  

Filename

Specify the data file used for the Play and Record modes.
