Voltage Probe

Overview

Voltage probes can be used to capture voltage data on a wire and display on a graph or to halt the simulation when a particular voltage condition is reached (hardware breakpoint). To record data on a graph you must apply the voltage probe to the wire of interest and then seperately add it to the graph.

Options

Probe Name

Enter the name of the probe here. Once you have manually changed the name of a probe, ISIS will never replace it, even if you move the probe to a new net. If you want a probe to revert to automatic naming, clear its name to the blank string and then click OK.

Resistive Loading

  • Load to Ground? - Specify whether you want to define a resistance to ground from the voltage probe. Use this where the probe is connected to a point which does not have a DC path to ground.
  • Load - Enter a value for the resistance from the probe to the ground net, and specify which, if any, properties of the probe you want to be visible on the schematic.

Waveform Recording

  • Record to File? - When checked the output data will be recorded to a partition data file.  If you do not specifiy a path, the file will be stored in the RESULTS directory.
  • Filename - Specify the filename and path for the output data, and which details you want to be visible on the schematic.

Real Time Breakpoint

  • Trigger Value - Specify the value at which you wish to halt the simulation. If digital, this amounts to 0 for logic low and 1 for logic high whilst in the analogue domain you simply enter the desired voltage.
  • Arm at Time - It is often useful to disable the condition until a particular point in time (e.g. after initialisation logic). The arm time represents the time at which the breakpoint becomes active.

Isolate After?

When checked a voltage probe placed in the middle of a wire acts to 'break' the wire to which it is connected, isolating the circuitry to which the probe connects from the circuitry after it.
