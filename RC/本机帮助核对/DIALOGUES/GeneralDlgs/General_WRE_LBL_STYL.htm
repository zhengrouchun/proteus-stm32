Edit Wire Label Style

Options

Global Style

Select a Global Style from the drop down list. Local changes (i.e. changes persistent only in the existing design ) can be made to the selected Global Style by unchecking the appropriate Follow Global? Checkbox.

Fontface

You can change the type of font used for this particulat script by unchecking the Follow Global? Checkbox and selecting a font face from the drop down list. A preview of your selection will become visible in the Sample viewscreen.

Height

You can change the height of the specified font by unchecking the corresponding Follow Global? checkbox and entering the required value. All changes will be local to the current label.

Width

Where appropriate the font width can be changed by unchecking the corresponding Follow Global? chackbox adnd entering the required value. This option is not available for TrueType™ Fonts.

Effects

When the appropriate Follow Global checkflag is unchecked local changes can be made to the font style by checking or unchecking this option.

Colour

Change the colour of the script text to one of the alternative colours shown.  This option is only available when the corresponding Follow Global? checkflag is unchecked,

Sample

Displays a visual representation of the text style currently specified.
