Block Rotate/Reflect

Overview

This dialogue form allows you to rotate highlighted items by a specific angle and mirror the highlighted items in the x or y axes.

Options

Angle

Choose the angle at which you wish the selected items to be rotated by.

Mirror X

Check this box if you wish the selected items to be mirrored in the x axis

Mirror Y

Check this box if you wish the selected items to be mirrored in the y axis
