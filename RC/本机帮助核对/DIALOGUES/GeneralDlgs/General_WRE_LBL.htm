Edit Wire Label

Overview

This dialogue allows you to specify a wire label. Common uses for wire labels include naming e a bus tap, naming a net and applying a net class to the net (CLASS=xxx). The latter is particularly useful when laying out the PCB as you can apply design rules and trace/via styles on a net class basis.

Options

String

Specify the script text. This field can be manipulated using the standard windows shortcut keys for cutting copying and pasting.

Auto-sync?

When checked this will ensure that all wire labels on the net carry the same text at all times.

Rotate

Specify whether the text is oriented horizontally or vertically.

Justify

Selects whether the text is left, centre or right justified, and whether it its origin is at the top or bottom.
