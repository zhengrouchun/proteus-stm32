Current Probe

Overview

This dialogue allows  you to configure current probe objects that are connected to wires on the schematic.

Options

Name

Enter the name of the probe here. Once you have manually changed the name of a probe, ISIS will never replace it, even if you move the probe to a new net. If you want a probe to revert to automatic naming, clear its name to the blank string and then click OK.

Record to File

When checked the output data will be recorded to a partition data file.

Filename

Specify the filename and path for the output data, and which details you want to be visible on the schematic.
