Edit Text

Overview

This dialogue allows you to configure a single line text entry. Note that this is different from a script block which is a multi-line text entry on the schematic. All changes to styles made here are local to the current text line; global changes should be made via the Template Menu.

Options

String

Enter a text string here.

Justification

These checkboxes allow you to define the required justification for the text.

Graphic's Style

  • Global Style - Specify which global Graphics style you want the text to be formatted in. Previews are shown in the Sample window.
  • Line Width - The width of line used to draw text when drawn in a vector font face. This field is disabled when either a TrueType™ font  face is selected (for which a line width is meaningless) or where  the Follow Global? checkbox is checked (which indicates the line width is to taken from the global style selected in the Global Style selector).
  • Colour - Specify a local ( object-specific ) colour. This is only enabled when the Follow Global? checkbox is unchecked.
  • Follow Global? -  If checked, the associated style attribute is initialised from the global style indicated in the Global Style selector. Unchecking the Follow Global? checkbox enables the dialogue control for the associated style attribute allowing you to specify a local (object-specific) value for that attribute.

Font Attributes

  • Font Face - Specify the name of the font face the text is to be displayed in. The drop down list lists all the TrueType™ fonts available on the machine as well as two special fonts: Default Font and Vector Font.
  • Height - Specify the height of the text. You can use whatever standard units you like, such at th for thou (thousandths of an inch) or mm for millimetres.
  • Width - Specify the width of a character in the text. This field is only enabled for text to be drawn in the internal Vector Font (either explicitly or by selecting the Default Font where the default font has been set to be the Vector Font.)
  • Bold? - Select Bold Text.
  • Italic? - Select Italic Text.
  • Underline? - Select Underlined Text.
  • Strikeout? - Select text with a strikeout.

Sample

Displays a sample of text drawn with the current style settings.
