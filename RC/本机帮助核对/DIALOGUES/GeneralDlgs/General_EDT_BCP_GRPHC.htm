Edit Box/Circle/Path Graphics

Overview

This dialogue allows you to make local changes to one or more graphics styles on the schematic. Global changes (for future designs) should be made via the Template menu.

Options

Global Style

Specify the global graphics style on which to base the appearance of the wire. Individual aspects of the wire’s appearance can be adjusted by unchecking the Follow Global checkboxes.

Lock controls to global style's current settings?

When checked this will disable any controls on the dialogue whose settings are meaningless as a result of the Global Style Settings.

Line Attributes

  • Line Style - Specify a local change to the Line Style. This is enabled only when the appropriate Follow Global? Checkbox is unchecked and any changes made are specific to the current wire.
  • Width - Specify a local change to the Line Width. This is enabled only when the appropriate Follow Global? Checkbox is unchecked and any changes made are specific to the current wire.
  • Colour - Specify a local change to the Line Colour. This is enabled only when the appropriate Follow Global? Checkbox is unchecked and any changes made are specific to the current wire.
  • Follow Global? - When checked the Line Style/Width/Colour will follow the global style as set in the Template Menu.

Sample

This displays a sample of the graphic reflecting any changes you have effected through the options given.

Fill Attributes

  • Fill Style - Specify which type of fill style you wish to use.
  • Fg Colour - Specify the colour of the graphic.
  • Use Bk. Colour For particular graphic types only, this option allows you to use a background colour.
  • Bk. Colour - If enabled, this option allows you to choose which background colour to use.
  • Follow Global? - These checkboxes determine whether the graphic(s) being edited should use the default style properties (as defined via the Template Menu) or should be overriden for the current graphics.
