Edit Component

Overview

This dialogue form is the main editing window for the object. Users can add fields to the dialogue form by specifying additional properties for the component in the Make Device dialogue form. This means that each component can contain arbitrary information relevant to that particular device. The options detailed below are therefore simply some of the most common that will be found in Labcenter produced library parts.

Options

Component Reference

Specify the part ID for the component. If the component is part of a multi-element part such as a 7400, use the naming syntax U1:A, U1:B etc. to select the different gates. ISIS will update the pin numbers automatically, when the part reference is so edited.

Hidden - If checked the component reference will not be visible on the schematic.

Resistance

Specify the component's part value.

In ISIS 5.1, the data type, description and value range for this field can be defined for each device type by giving a property definition for the VALUE property.

Hidden - If checked the component value will not be visible on the schematic.

Model Type

If present, this field specifies whether a component is considered digital, analog or mixed mode by the Proteus simulation engine. Only applicable for parts with simulation models and therefore typically only present in Labcenter produced library parts.

PCB Package

When present, this field allows specification of one or more PCB footprints which are associated with the component for the purposes of PCB layout. This field is present on most physical devices and is used when netlisting to the ARES layout software to load the footprint for placement.

Other Properties

A free format text block in which you can add as many additional properties as you require. Text enclosed between curly brackets ('{' and '}') is hidden.

See also the Edit all Properties as Text button.

Exclude from Simulation

This option provides the means for a user to exclude parts from a simulation but leave them present on the schematic for physical netlist purposes. For example, connectors and crystals should not be simulated but would need to be present for PCB layout.

Exclude from PCB Layout

This options provides the means for a user to exclude parts from a PCB but to include them when simulating the schematic. For example, non-physical parts such as oscilloscopes and logic analysers are used in the simulation but are not present in the physical layout of the board.

Edit all properties as text

If checked, then all component properties are placed into the free format text block. This bypasses the syntax checking present when property definitions are in use, and allows you to enter parameterized expressions for the property values.

In addition properties specified as HIDDEN by their property definitions can be viewed and/or edited.

Recommended for advanced users only.

Attach hierarchy module

If checked, this option causes a child sheet to be attached to the component. You can access the child sheet by pointing at the component and pressing CTRL+'Z'.  The name used for the child sheet is determined when the device was made via the External Module field of the Make Device Dialogue form. If no external module was specified, ISIS uses the name of the device itself.

This behaviour is different from ISIS versions prior to 5.1. Backward compatibility for old designs is retained.

Hide common pins

When checked, all the common pins on the element being edited will be hidden. This is intended for use with multi-element homogeneous parts where you only want the common power pins on one or more elements to be hidden. For example, with a quad op-amp you might only want power pins visible on one element and would therefore use this option to suppress the common power pins on the other elements.

This option will be disabled for components with no common pins.
