Align Components

Overview

This command allows you to automatically align selected objects on the schematic according to the set criteria. To select multiple objects for aligning either :

  • Drag a tagbox around the objects.
  • Left click to select an object and then hold the CTRL button down while left clicking to select additional objects.

Options

Action

This determines what the reference point for the aligning operation should be. You can choose to align to any edge or to center either vertically or horizontally.

Align Point

This combo box allows you to choose between using the Object Bounds or the Connection Points as the Align Point. This determines which part of the object is considered when aligning in the manner specified through the Action options.
