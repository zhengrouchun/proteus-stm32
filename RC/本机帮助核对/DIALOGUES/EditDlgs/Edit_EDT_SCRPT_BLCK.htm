Edit Script Block

Overview

This dialogue form allows you to change the text and style of a script block on the schematic. Changes to the style via this dialogue form are local to the script you are editing; persistent or default changes should be made via the Set Text Styles command on the Template Menu

Options

Text

Modify the properties of the script block here. You can exit the form using Ctrl & Enter. You can change the default size of the script block window by clicking on the ISIS icon at the top left of the dialogue form and selecting Save Window Size.

Rotation

Select whether the text is oriented horizontally or vertically.

Justification

Select whether the text is left, centre or right justified, and whether it its origin is at the top or bottom.

External File

  • Import - Imports text from a text file on your hard disk.
  • Export - Export the script block to a text file.
