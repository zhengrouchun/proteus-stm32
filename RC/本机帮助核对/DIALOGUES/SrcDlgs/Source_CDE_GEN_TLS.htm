Add/Remove Code Generation Tools

Overview

This dialogue is relevant to microprocessor simulation and allows you to configure command line interfaces to your compiler/assembler such that Proteus can invoke them and build your projects.

Note that it is perfectly possible to work inside your own IDE/Compiler environment and to then simply edit the processor component on the schematic and specify the file to be simulated directly.

Options

Code Generation Tool

Use these options to specify or change the Code Generation Tool to be used for files in the current design.

  • Tool - Select a Code Generation Tool from the list. You can add to the list using the New Button at the bottom of the form.
  • Browse - Search your computer to find an appropriate Code Generation Tool. Both executable (EXE) and batch (BAT) files can be selected.
  • Path - Search your computer to find an appropriate Code Generation Tool. Both executable (EXE) and batch (BAT) files can be selected.

Make Rules

Use these options to specify specific Make Rules for the Code Generation tool currently listed above.

  • Source Extn - Specify the file extension for the Source file. For example, with an Assembler as the Code Generation Tool, the Source extension would normally be "ASM".
  • Obj Extn -  Specify the file extension for the Object file. For example, with an Assembler as the Code Generation Tool, the object extension would normally be "HEX".
  • Always Build - When checked the project will always be compiled before the start of a simulation.
  • Command Line - Specify the arguments used on the command line to apply the Code Generation Tool to a source file. Substitute ‘%1’ for the source file and ‘%2’ for the object file.

Debug Data Extraction

Use these options to specify a Debug data Extraction (DDX) tool for the given tool. This is only necessary if you are using a supported assembler and should not be used if you are using a high level language tool.

  • List File Extn - Specify the extension of the list file generated from the Code Generation Tool. For example, with an assembler as the Code Generation Tool, the list file extension is normally "LST".
  • Browse -  Browse for the location of the debug data extraction tool on your computer.

Other

  • Disable Automatic Build Rules - This option disables any automatic building selections that you have made and applies globally to all tools configured in this dialogue.
  • New - Specify a new Code Generation Tool.
  • Remove - Remove a Code Generation Tool.
