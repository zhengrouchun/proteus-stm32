Add/Remove Source Code Files

Overview

This dialogue is relevant to microprocessor simulation only and provides a user interface to specifying the source file(s) and compiler tools for creating the binary file on which the processor will run.

Note that it is perfectly possible to work inside your own IDE/Compiler environment and to then simply edit the processor component on the schematic and specify the file to be simulated directly.

Options

Target Processor

Specify the target processor on the schematic - since it is possible to simulate multi-core designs in Proteus you must identify the target for each source file.

Code Generation Tool

Use these options to specify or change the code generation tool to be used with the given source file. New Code Generation Tools can be specified from the Define Code Generation Tools command on the Source Menu.

Flags - Specify any arguments to be appended to the command line when applying the Code Generation Tool to the given Source File. These flags are applied just to the compilation of this source file.

Source Code Filename

Use these options to select or change a source code file

  • Change - Substitute the highlighted source file for a different source file.
  • New - Add a source file to the design.
  • Remove - Remove a source file from the design.
