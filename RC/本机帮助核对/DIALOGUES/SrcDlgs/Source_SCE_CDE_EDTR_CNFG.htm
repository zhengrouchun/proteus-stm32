Source Code Editor Configuration

Overview

This dialogue allows you to specify an editor for working with source files. Used in conjunction with the other dialogues on this menu you can write and compile your code using the Proteus environment.

Note that it is perfectly possible to work inside your own IDE/Compiler environment and to then simply edit the processor component on the schematic and specify the file to be simulated directly.

Options

Executable

Search your computer for an appropriate Source Code Editor.

DDE Interface

Use these options to specify a DDE interface for a text editor of your choice. Each option has its own context sensitive help topic.

  • Service Name - Specify the service name of the Source code Editor.
  • Open Command - Enter the command used by the Source Code Editor to open a file. Substitute ‘%1’ for the source file.
  • Save Command - Enter the command used by the Source Code Editor to save a file.
