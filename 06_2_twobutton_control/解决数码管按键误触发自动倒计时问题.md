# 解决按键接口不一致与数码管重复计数问题

## 问题和实际原因

本次读取到的 button.c 把 buttonflag 当成累计数字：按钮一执行 buttonflag++，按钮二执行 buttonflag--，buttonflag_get() 返回该数字且不清空。main.c 却把返回值当成一次按键事件，并反复加减。两处含义不一致，造成一次按键后数字继续变化。此外，按键回调中通过 while 等待松手，会阻塞中断处理；uint8_t 的 0 减一变为 255，也不等于本业务要求的 99。

此前用 int8_t 和 -1 表示减一事件，虽可表达方向，但不符合用户指定的 uint8_t 接口。本次统一改为无符号按键编号：0 无按键，1 按钮一，2 按钮二。

## 修复流程和方法

1. 阅读最新 button.c、button.h、main.c，追踪按键返回值、主循环加减条件及中断中的等待循环，确认累计值和事件编号被混用。
2. button.c 只保存按键编号，不再保存显示数字。buttonflag_get() 保持 uint8_t，读出编号后立即清零；短暂关闭中断完成读出和清零，再恢复原中断状态，避免新事件被误清除。
3. 删除回调里的 while。根据 GPIO_Pin 识别中断来源，只有低电平且消抖结束时记录编号；松开不产生加减事件。
4. 保持双边沿 EXTI。按下、松开和弹跳边沿都会重新开始该键的 20 ms 消抖；TIM2 每 1 ms 递减两个消抖计数，期间忽略重复边沿。没有 HAL_Delay，也没有在中断里等待松手。
5. main.c 只用 number 和 key 两个业务变量。number 是 uint8_t 显示数字；key 是 uint8_t 按键编号。按钮一在 number 为 99 时直接设为 0，否则加一；按钮二在 number 为 0 时直接设为 99，否则减一。先检查边界，避免无符号数减到 255。
6. 保留 display.c/.h 的扫描逻辑。TIM2 回调调用 Button_TimerTick() 推进消抖，调用 Display_TimerTick() 请求刷新，两者都不修改显示数字。
7. 使用本机 Keil ARM Compiler 5.06 完整重编译、链接并生成 HEX：0 Error(s), 0 Warning(s)，进程退出码 0。未执行 Proteus 或实机仿真。

## 变量用途

- main.c 的 number：数码管显示数字，0 到 99。
- main.c 的 key：本次取出的按键编号，0、1 或 2。
- button.c 的 buttonflag：中断记录、尚未被主循环取出的编号，读取后清零。
- button.c 的 key1_delay、key2_delay：各键剩余消抖毫秒数；为 0 才接受新按下。
- buttonflag_get() 内的 key：临时保存取出的编号。
- buttonflag_get() 内的 irq_state：保存函数调用前的中断开关状态，以便准确恢复。
- callback 内的 GPIO_Pin：当前触发 EXTI 的引脚编号。

共享编号和消抖计数使用 volatile，因为它们会被中断修改。新增功能语句均附中文用途说明，未使用 0U 等整数字面量后缀。

## 阅读及使用的文件位置

- MyCode/button.h：uint8_t buttonflag_get(void)、Button_TimerTick() 及 EXTI 回调声明。
- MyCode/button.c：按键编号读取与清除、TIM2 消抖计数、按下/松开 EXTI 回调。
- Core/Src/main.c：USER CODE Includes 引入模块；USER CODE 2 初始化业务变量并启动 TIM2；USER CODE WHILE 处理编号和回绕；USER CODE 4 调用模块节拍接口。给主程序实际语句补充中文注释。
- MyCode/display.c、display.h：阅读确认扫描十位/个位和刷新标志的接口，不改显示逻辑。
- Core/Src/gpio.c：PB3/PB4 上拉、双边沿 EXTI 和 EXTI3/4 的 NVIC 配置；补充双边沿用途说明。
- Core/Src/stm32f1xx_it.c：EXTI3/4 调用 HAL_GPIO_EXTI_IRQHandler；补充清除中断标志和进入回调的说明。
- Core/Inc/main.h：确认 KEY1 是 PB3、KEY2 是 PB4。
- Core/Src/stm32f1xx_hal_msp.c：确认已关闭 JTAG，PB3/PB4 可供按键使用。
- Core/Src/tim.c：确认 Prescaler=79、Period=99，当前 8 MHz 时钟下为 1 ms。
- 06_2_two_button.ioc：确认双边沿 EXTI、NVIC 和 TIM2 配置。
- MDK-ARM/06_2_two_button.uvprojx：确认 button.c、display.c 及 MyCode 头文件路径已登记。

## 目标行为

上电显示 00。每次有效按下按钮一加一；每次有效按下按钮二减一。99 再加一显示 00，00 再减一显示 99。未读取到新按键时 number 不变，按住期间只刷新显示。
