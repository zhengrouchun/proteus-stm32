## 先认清你当前画面中的器件

你图里的`U1 STM32F103C8`留在右侧；`BAT1 1V`作为DIV首轮测试源；`R1 10k`作为被测的R1；`SW1 SW-SPST`作为R1断路开关；`SW2 SW-SPST-MOM`留给NRST复位。还需要复制/新增`RES`，分别设为`RS=2k`、`R2=10k`、`BOOT0下拉=10k`、`NRST上拉=10k`。另外复制/新增一只`SW-SPST`，作为R2短路开关；再放一个`CELL`设为3.3V，为MCU独立供电。`C1=100nF`用作3.3V去耦。

你当前图中有**两颗`24LC256`（U2和U3）**，完整方案只需一颗。现阶段把两颗都停放在图边，不连接，之后选一颗接入。矩阵显示器、`C2=10µF`、OLED、LED、虚拟终端、示波器、`VSWITCH S1`也先放在图边；这些不是第一轮DIV电压表验证的必需元件。这样做的目的，是先排除最简单的接线错误。

`SW1`和`R1`只要**串联在VA和VB之间**，二者左右顺序互换不影响这三种工况。为了跟第一张新图完全一样，可以把`SW1`摆在`R1`左边；不想移动已有元件也可以保持`R1`在左、`SW1`在右。

在你截图的界面，新增器件可按键盘`P`、输入`RES`或`SW-SPST`、双击合适搜索结果，再回图纸左击放置；要把电阻横放或竖放，选中元件后使用左上角的旋转箭头。双击图上的元件设置`Value`。接线时从器件的红色引脚端点左击开始，移到目标引脚再左击，中间想拐弯就先左击一次定位折点；按`Esc`退出正在画的导线。放好后放大核对：应当看到绿色导线真正接到引脚，三线相接处有结点点；仅仅在视觉上贴近却没有连接不算。左侧`LBL`工具用于给**已有绿色导线**加网络名，不是直接放在空白处。底部三角形“运行”按钮开始仿真，方形“停止”按钮结束本轮，修改接线前先停止。

## 第一步：只搭DIV，按图一从左到右

1. 在U1左侧空白区域摆`BAT1`，正极朝上；它只供应1V测试电路。右侧依次排`RS(2k)`、`VA节点`、`SW1`、`R1(10k)`、`VB节点`。把`R2(10k)`竖放在VB下面，R2下端接`GND`。
2. 再放一只`SW-SPST`在R2右侧，与R2并联：上端接VB、下端接GND，作为R2短路开关。它的位号由Proteus自动分配，图中叫`SW3`；**认位号以实际图为准，认功能以“VB至地并联开关”为准**。
3. 用导线连：`BAT1正极 → RS → VA → SW1 → R1 → VB → R2 → GND`。`BAT1负极 → GND`。R2短路开关的两个端点跨接VB和GND。导线拐角用正交折线；只有需要电气连接的交点才应显示结点小圆点。
4. 在左侧`Terminals`模式放`GROUND/GND`，给BAT1负极和R2下端接同一个公共地。不要将BAT1正极直接接MCU的3.3V电源。
5. 在另存且删除U1的纯模拟测试副本中，放两个`DC VOLTMETER`：表A正端接VA、负端接GND；表B正端接VB、负端接GND。当前只有一只表也可以：先量VA并记录，再把正表笔改接VB并记录，负表笔始终接GND。
6. 双击`RS/R1/R2/BAT1`，核对值依次为`2k/10k/10k/1V`。图上器件名（例如R1）是位号，`10k`才是数值；不要把`2k`当作搜索词。
7. 开始仿真。正常状态`SW1闭合`、R2并联开关`断开`；随后只打开SW1测R1断路；恢复SW1，再只闭合R2并联开关测R2短路。每切换一次，等表读数稳定后再记录。仿真开关通常可在运行时点击手柄切换；是否闭合以图上触点相接、测量值符合预期为准。

1V理想值如下，允许显示尾数有微小差别：正常`VA≈0.909V、VB≈0.455V`；R1断路`VA≈1.000V、VB≈0V`；R2短路`VA≈0.833V、VB≈0V`。**两种故障的VB都约为0V，必须同时看VA才能区分。**若三种状态都量得0V，优先检查BAT1负极接地、开关状态、表的正负端以及电阻是否真正连在绿色导线上。

## 第二步：给U1供电，再接ADC和程序

1. 新放`CELL`，设为`3.3V`。从其正极拉一根3.3V母线，母线上放名为`VDD`的电源端子，并由**同一根导线**分支接到U1第9脚`VDDA`与第1脚`VBAT`；不要把`VDD`和`3.3V`做成两条未连通的线。负极接公共GND，在同一接地网络上放与U1隐藏电源脚相符的`VSS`端子，并接U1第8脚`VSSA`。U1图中隐藏的VDD脚为24/36/48、VSS为23/35/47；检查器件属性或仿真网表，确认它们确实连到这一路3.3V和GND。`C1=100nF`跨接3.3V与GND。
2. U1第44脚`BOOT0`经10kΩ到GND；第7脚`NRST`经10kΩ上拉到3.3V，已有的`SW2 SW-SPST-MOM`从NRST接到GND，按下复位。第5、第6脚暂不接晶振；程序时钟选择片内HSI 8MHz，HSE与PLL关闭。在U1属性里将时钟设为8MHz，并加载**实际按HSI 8MHz编译**的程序；只改Proteus时钟属性不会改固件时钟树。
3. 从VB拉一小段线到U1第10脚`PA0`；从VA拉一小段线到第11脚`PA1`。线路长时，可在VA线段和PA1线段上都用图形窗口左侧的`LBL`工具标`DIV_VA`，在VB线段和PA0线段上都标`DIV_VB`。两端标签必须逐字一致、确实贴在**导线上**；最后通过节点高亮或网表确认同名线实际相连。
4. 固件把`PA0`作为ADC1通道0、`PA1`作为ADC1通道1，先输出**原始ADC码值**，再按实际参考电压和码值范围换算mV。STM32F103C8芯片ADC为12位，但所用流程图库的API是否返回完整12位，须用0V/1V/3V校验，不能提前认定。第一轮只要求三个工况真实读数、能够在串口或屏幕辨认三种结果。

**重要顺序：**电压表三工况正确，只证明模拟电路连接初步正确；ADC三工况正确还要求U1供电、程序、时钟和ADC采样均正常。记录时把两类结果分开写。

## 第三步：用C2搭RC，然后再扩展VSWITCH

先照第二张图上半部独立搭`1V源 → 2kΩ → RC_VA → 10kΩ → RC_VB → C2(10µF) → GND`；C2正极接RC_VB，负极接GND。`RC_VB → PA2第12脚`，`RC_VA → PA3第13脚`。这一步暂不接1V/3V切换开关。电容充电前应放电到接近0V，再施加1V阶跃；示波器A通道接RC_VB，参考端接公共GND，观察起点和上升曲线。该最小电路理论时间常数是`(2kΩ+10kΩ)×10µF=120ms`。

你已放的`S1 VSWITCH`不要当作手动故障开关。按你截图的符号，**上下两个端子**是开关主回路，左边有`+`标记的端子与其下面的端子是控制输入；放到独立小测试电路里核对它的导通逻辑。扩展阶段让1V源正极经一只VSWITCH接被测电路源端，让3V源正极经另一只VSWITCH接同一源端；两个源负极分别接公共GND。控制正端分别接PB脚，控制负端接GND；程序互锁，两个开关绝不能同时闭合。首轮固定1V验证时，**不需要**把VSWITCH接进来。

## 第四步：外围元件分别做什么

- `OLED12864I2C`：1脚GND接地、2脚VCC接3.3V、3脚SCL接U1的PB6/第42脚、4脚SDA接PB7/第43脚；需要实际程序初始化后才显示文字。
- 一颗`24LC256`：截图符号的6脚`SCK`接PB6、5脚`SDA`接PB7、7脚`WP`接GND，A0/A1/A2均接GND；SCL/SDA各用4.7kΩ上拉至3.3V。截图上器件电源脚不露出，必须查看器件属性/网表，确认其隐藏VCC/GND接到了正确网络。第二颗先不接，避免地址冲突。
- 四只`SW-SPST-MOM`操作键：一端分别接PA4/第14脚、PA5/第15脚、PA6/第16脚、PA7/第17脚，另一端接GND；GPIO配置上拉输入，按下读0。你现在的`SW2`优先做NRST，因此若要四个操作键需另外再复制四只。
- 绿/红LED：PB13/第26脚、PB14/第27脚各串1kΩ限流电阻，再接对应LED阳极，LED阴极到GND。先根据Proteus符号标出的阳极/阴极核对方向，不以器件画在上方还是下方判断极性。
- `VIRTUAL TERMINAL`：其`RXD`接U1的PA9/第30脚TX；只有程序发出串口文本才有记录。`TXD/RTS/CTS`首轮不用。`OSCILLOSCOPE`观察RC波形，`DC VOLTMETER`查看固定节点电压；截图左下的矩阵显示器不是本方案首轮所需器件。

## 每次仿真到底记录什么

先填写[DIV三工况实测记录模板](D:/Proteus/project/检路操作指南/解决DIV三工况数据如何记录的问题.md)。一条记录至少写：日期、工程文件名和备份位置、Proteus版本、固件文件与时钟配置、实际电源值、三个电阻值、两个开关的开/合状态、**VA/VB电压表读数**、**PA1/PA0原始ADC码**、按实测参考电压换算的mV、程序输出的类别、运行供电状态、截图文件名、异常现象。没有加载固件时ADC码和程序输出栏写“未测试”，不可把理论数填成实测。

每个工况保存一张截图，截图要同时看见开关状态、两只电压表、U1或节点标签、仿真运行状态；若不能同时显示，就分别截电路和串口输出，并用同一个工况编号命名。三工况通过后，再按原有`仿真记录_18工况.csv`扩展到DIV/RC各九工况。RC还需记录放电后的起始VB、示波器测得的1V阶跃起点、实际50ms/55ms采样时刻和两点电压，不可只写程序里设定的延时值。
